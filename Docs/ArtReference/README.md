## 오카미에서 가져올 것
- **먹 외곽선**: 굵기가 일정하지 않은 붓 선. 모델에 외곽선 셰이더 하나로 통일감을 줌.
- **종이 질감 오버레이**: 화면 전체에 한지 질감을 얇게 덮음 (화면 위 그림 한 장 → 가벼움).
- **평평한 색 + 수채 그라데이션**: 복잡한 텍스처 대신 넓은 면의 옅은 색.
- **이펙트를 문양으로**: 흙먼지·폭발·바람을 사실적인 파티클이 아니라 **소용돌이·구름 문양 그림**으로 → 가볍고 개성 있음.
- **먹물 그림자**: 캐릭터 아래 검은 먹 덩어리 그림자 = 블롭 섀도 (실시간 그림자 불필요).
- **UI**: 종이 카드, 붓 획 체력바, 먹 단지 모양의 충전 표시 → 귀살의 **충전식 물약(보혈환·청심환) 표시**에 그대로 응용.

## 귀살이 다르게 갈 것 (일본풍이 아니라 한국풍으로)
오카미는 **일본** 미술(우키요에, 일본 신화) 기반입니다. 그대로 따라 하면 일본풍 게임으로 보일 수 있으므로, 같은 기법에 **한국 소재**를 씁니다.

| 오카미 (일본) | 귀살 (한국) |
|---|---|
| 일본식 지붕, 토리이(鳥居) | 한옥 처마 곡선, 기와, **단청**, 일주문, 홍살문 |
| 우키요에 색감 | **민화·오방색**(청·적·황·백·흑) 색감, 한국 산수화의 먹 번짐 |
| 일본 구름 문양 | 한국 전통 **구름무늬(운문)**, 태극·만자 문양 |
| 여우 가면 등 일본 요괴 | **탈(하회탈 등)**, 장승, 한국 민담 귀신 |
| 밝고 화사한 낮 | 더 **차분하고 어두운** 톤 (안개, 밤, 저승) — 귀신 이야기에 맞게. 단 중요한 것(부적·피해·체력)에만 선명한 색 |

## AI 컨셉 그림 검토 (2026-10-18)
- **잘 된 점**: 수묵 선·한지 바탕·옅은 색이 기획과 맞음. 붉은 먹 폭발과 노란 부적이 눈에 띔. 한국 소재(초가·장독·석탑·단청·오색 천)가 잘 나옴. ①②는 같은 주인공 모습으로 나와 통일감 있음.
- **고칠 점 (다음 프롬프트에 반영)**: 귀신이 모두 긴 머리 흰옷 처녀귀신 + 반투명 → 기획은 **불투명 + 테두리 빛**, 망자는 **회색 피부의 마을 사람 모습**. 일본식 석등 주의. 무너진 본산은 더 부서지게.
- **게임 화면은 이보다 훨씬 단순**: 컨셉 그림은 "목표 분위기"이고, 3D 게임에서는 모양을 단순하게 하고 외곽선 셰이더·한지 질감으로 이 느낌을 냄.
