## 3. 완료된 기능 ✅

### 1단계: 기본 조작

- [x] 좌클릭 바닥 이동 (NavMesh 길찾기, 누르고 있으면 계속 이동)
- [x] 적 클릭 타겟팅 → 다가가서 사거리 안에서 멈추고 바라보기

### 2단계: 전투

- [x] 적 체력(HP)과 사망
- [x] 공격 속도(Attack Rate) 쿨타임
- [x] 플로팅 데미지 텍스트 (튀어나와 떠오르며 사라짐)
- [x] 치명타(Critical) — 10% 확률로 2배, 크고 빨간 "20!" 숫자 (근접·부적·폭발 모두)
- [x] 플레이어가 맞을 때 보라색 데미지 숫자
- [x] 피격 시 적이 하얗게 번쩍이기(발광) + 넉백 (공격 방향별, 치명타는 2배)
- [x] 부적 적중 시 금색 불꽃 이펙트 (파티클 시스템)
- [x] 클릭한 바닥 위치 표시 (하늘색 동그라미, 새 클릭만, 하나만 표시)

### 3단계: 루팅

- [x] 적 사망 시 아이템 드랍 (위로 튀어 오름, 등급 4종: 노멀 70% / 매직 20% / 레어 9% / 유니크 1%)
- [x] 드랍 아이템 착지 후 제자리 고정
- [x] 아이템 클릭 → 다가가서 줍기
- [x] 여러 종류의 아이템 랜덤 드랍 (드랍 테이블: 무기 4종·방어구 4종, 가중치 확률)
- [x] 바닥 아이템 위에 등급 색 이름표 (항상 카메라 정면, 주우면 함께 사라짐)
- [x] 기력 물약(Mana Potion) 드랍과 사용 (30% 드랍, 가방 묶음 표시, 1 키·클릭으로 마시기)

### 4단계: 성장 & UI

- [x] 인벤토리 (I 키로 열기/닫기)
- [x] 경험치(XP)와 레벨업 (최대 체력 +20, 공격력 +5, 필요 경험치 ×1.5)
- [x] 체력바 / 경험치바 / 레벨 텍스트
- [x] 스킬바 UI (부적·폭발 칸, 쿨타임 원형 덮개 + 남은 시간, 기력 부족 시 어둡게)
- [x] 물약 칸 UI (스킬바 오른쪽, 남은 기력 물약 개수, 0개면 어둡게, 클릭으로 마시기)
- [x] 디아블로식 격자(Grid) 인벤토리 (6×5 = 30칸, 아이콘 + 등급 색 테두리, 물약 묶음 ×N, 가득 차면 줍기·해제 불가)
- [x] 장비 칸 아이콘 (무기·방어구 칸 왼쪽 아이콘 + 등급 색 테두리, 비면 회색)
- [x] 아이템마다 다른 아이콘 (장비 8종 전용 그림, `Resources/ItemIcons`에서 이름으로 찾기, 없으면 공용 아이콘)

### 5단계: 적 AI & 필드

- [x] 적 추격 & 반격 AI (인식 거리 10m, 공격 사거리 1.5m)
- [x] 플레이어 피격과 사망 (조작 정지)
- [x] 사망 화면("YOU DIED") 페이드 인 + 부활 버튼 (시작 위치 부활, 2초 무적·깜빡임)
- [x] 적 머리 위 체력바 (맞으면 배경과 함께 나타남, 항상 카메라 정면)
- [x] 몬스터 스포너 (3초마다, 최대 5마리, NavMesh 위에만 생성) — 무리 배치 방식으로 바뀜
- [x] 스포너 최소 거리 (플레이어 6m 안에는 적 생성 안 함, Scene 뷰 노란 원 표시) — 무리 배치에서는 18m
- [x] 몬스터 종류 + 챔피언·유니크 무리 배치 (디아블로 방식, 웨이브 제거)
  - 게임 시작 시 맵(NavMesh, 100m × 100m) 전체에 무리를 한 번 배치 (다시 채우지 않음): 일반 무리 6~9개 / 챔피언 무리 1~3개 (챔피언 2~4마리, ×2) / 유니크 무리 1~2개 (유니크 ×3 + 하수인 3~4마리 ×1.5)
  - 몬스터 4종 (잡귀·강시·아귀·도깨비, 임시 이름), 등급별 색·이름표, 등급별 장비 드랍 개수·좋은 등급 확률 배율, 시작·모두 처치 알림

### 6단계: 스킬

- [x] 부적 투사체(Amulet Projectile) — 마우스 우클릭
- [x] 기력(MP) & 부적 폭발(Amulet Explosion) — Q 키 (MP 바, 자연 회복, 범위 데미지, 서서히 사라지는 폭발)
- [x] 스킬 데미지를 공격력(Attack Power)과 연동 — 부적·폭발 모두 공격력 ×2 (레벨업·무기 장착 시 함께 강해짐)
- [x] 부적 폭발 조준 원 — Q 누르고 있기: 범위 표시(금색/빨간색) → 떼기: 폭발, ESC 취소

### 7단계: 시스템

- [x] JSON 세이브/로드 (S 저장, L 불러오기, 사망 상태에서 불러오면 부활)
- [x] 기력(MP)도 세이브 저장 (세이브 형식 버전 2, 예전 파일은 기력 가득)
- [x] 장비 장착 (무기: 공격력 / 방어구: 최대 체력, 교체 시 기존 장비는 가방으로)
- [x] 아이템 툴팁 (마우스를 올리면 능력치·장착 장비 비교 ▲초록/▼빨강, "현재 → 장착 후" 수치, 화면 밖으로 안 나감)
- [x] 장비 칸 클릭으로 해제 (무기·방어구 칸 버튼, 해제 툴팁, 방어구 해제 시 체력 보정, 사망 중 변경 불가)
- [x] 카메라가 플레이어를 부드럽게 따라다니기 + 마우스 휠 줌
- [x] 화면 알림 (위쪽 가운데, 종류별 색, 떠오르며 사라짐 — 가방 가득 참·기력 부족·레벨 업·저장/불러오기 등)

## 7. 씬 & 에셋 구성

### 씬 구성 (S1-10부터)

- **`Core`** (Scene List 0번, 게임 내내 열려 있음): 플레이어·카메라·UI·관리자. 조명이 없어 에디터에서 어둡게 보이는 것이 정상
- **지역 씬** (`Region_01` 백팔 계단, `Region_02` 안개 산길 — 한 번에 하나만 추가로 열림): 조명·Global Volume·땅(NavMesh)·몬스터 배치기·입구·출구
- 새 지역은 지역 씬을 **복제**해서 만들고 Scene List에 추가, 화면 글자 표에 `region.name.씬이름` 추가
  - ⚠️ 복제한 씬에서 NavMesh를 **Bake하면 원본 씬의 NavMesh 파일이 지워짐** → 땅 모양이 같으면 Bake하지 않고 함께 쓰기, 땅을 바꿨으면 Bake 전에 NavMesh Surface의 데이터 연결을 끊거나 Bake 후 Git으로 원본 파일 확인
- 테스트: 지역 씬을 열고 Play 해도 자동으로 Core부터 시작 (`RegionPlayModeStarter`)
