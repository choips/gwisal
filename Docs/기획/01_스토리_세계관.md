### 게임 구조

- **싱글플레이 전용**.
- **스토리 진행형이 기본** (디아블로 3·4식): 메인 스토리 **3막**, 막마다 지역 → 보스.
- **서브 퀘스트**로 메인 스토리의 완성도를 끌어올립니다. (아래 "서브 퀘스트" 참고)
- **인스턴스 던전 "귀문 균열"**: 거점 마을에서 입장하는 반복형 던전. 무작위 맵·몬스터, 파밍·레벨업용. **1막 클리어 시 해금**.
- **거점 마을**: 정비·상점·의뢰. 서브 퀘스트를 해결할수록 마을이 되살아남.
- **디아블로 2처럼 처음부터 직업 선택**: 초기 직업 **3종** (아래 "직업 & 파밍" 참고). 어떤 직업이든 스토리는 공통.
- **엔딩 후 스토리 스킵**: 한 번이라도 엔딩을 본 뒤 만든 캐릭터는 메인 스토리를 건너뛰고 거점 마을 + 귀문 균열(파밍)에서 시작 가능.
- **DLC 확장**: 출시는 **3막 + 직업 3종**. 이후 DLC마다 **새 막 + 그 막과 어울리는 직업**을 묶어서 추가.

```
[새 캐릭터] 직업 선택 (부적사 / 퇴마검사 / 무당)
   [거점 마을] ← 정비, 상점, 의뢰
      ├─ 메인 스토리: 프롤로그 → 1막 → 2막 → 3막 → 엔딩 (고정 맵 + 무작위 지역, 이야기)
      └─ 인스턴스 던전 "귀문 균열" (무작위 맵·몬스터, 반복 파밍, 1막 클리어 후 해금)
[엔딩을 본 뒤 만든 캐릭터] → 메인 스토리 스킵 가능 → 거점 마을 + 귀문 균열 파밍
[DLC] 4막 "저승" + 신규 직업 승병 → 이후 같은 방식으로 막·직업 추가
```

### 세계관

- **배경**: 한국 민속을 모티브로 한 **가상의 동양 판타지 세계 "청구(靑丘)"**. 역사 고증에 묶이지 않음.
- **귀문(鬼門)**: 이승과 저승을 잇는 문. 청구 곳곳에 있음.
- **주묵(朱墨)**: 세상에 드러나지 않은 **비밀 도사 집단**. 이름은 부적을 그리는 **붉은 먹(朱)과 검은 먹(墨)**. 수백 년간 귀문을 지켜 온 도사 집단. 본산 깊은 곳의 **대귀문**을 지킴. **세 갈래(문파)**로 나뉨 = 초기 직업 3종.
  - **부적당(符籍堂)**: 부적을 쓰고 다루는 갈래 → 부적사
  - **검당(劍堂)**: 귀신을 베는 칼잡이 갈래 → 퇴마검사
  - **신당(神堂)**: 신을 내려 싸우는 갈래 → 무당
- **부적의 비밀 (3막에서 밝혀짐)**: 부적의 힘은 **망자의 혼을 태워서** 얻는 것이었다. 주묵은 문 너머의 혼을 가두고 연료로 써 왔고, 그 때문에 **저승의 윤회가 멈춰** 망자가 문 너머에 쌓이고 있다. 이대로면 청구 전역의 귀문이 동시에 터진다.
  - **이름에 숨은 원죄**: 부적의 **붉은 먹(주사)**에는 **태운 혼의 재**가 섞여 있었고(원죄), **검은 먹**은 그 사실을 적은 기록을 대대로 지워 온 손이었다(비밀). 조직의 이름이 처음부터 진실을 말하고 있었던 셈.

### 주요 인물

- **주인공 — 플레이어 캐릭터**: 주묵의 **마지막 생존자**. 시작할 때 고른 직업 갈래(부적당·검당·신당)의 **막내 대원**.
  - 직업별로 **짧은 고유 대사**만 있고, 스토리 흐름은 공통 (디아블로 2 방식). 대사량이 직업 수만큼 늘지 않게 함.
  - **망자의 목소리를 듣는 능력**: 문이 열린 밤, 죽어 가던 스승이 주인공의 손에 **부적 한 장**을 쥐여 줌 → 그때부터 망자의 목소리를 듣게 됨.
    - 원혼과 대화하는 서브 퀘스트의 근거.
    - 3막에서 이 부적이 **봉인 부적**이었다는 것이 밝혀지며 "왜 내가 목소리를 들을 수 있었나"까지 풀림.
  - **결말과의 연결**: 스승은 이승을 희생해 혼을 구하려 했고, 주묵은 혼을 희생해 이승을 지켰다. 망자의 목소리를 듣게 된 주인공은 **양쪽을 다 듣는 사람**으로서 스승을 막고 대귀문을 봉인함. (아래 "결말" 참고)
- **무영(無影) — 핵심 NPC**: 스승이 거둔 고아. 남자, 17~19세. 태어날 때부터 **망자의 목소리를 듣는 체질** 때문에 마을에서 버려짐. 이름 "무영(그림자가 없다)"은 스승이 지어 줌.
  - **성격**: 말수가 적고 무뚝뚝하지만, 혼에게는 이상할 만큼 다정함.
  - 프롤로그에서 주인공과 함께 살아남아 **거점 마을의 길잡이 NPC**가 됨.
  - 스승을 아버지로 여겨, 2막의 "문을 연 건 스승님이다"에서 가장 크게 흔들림.
  - 3막에서 스승의 뜻을 이해해 버리고 **스승 편에 설지 고민**함 → 최종전 중간에 플레이어가 무영을 붙잡는 장면이 감정의 정점.
  - **결말**: 스스로 대귀문 너머에 남아, 쌓인 혼들을 하나씩 윤회로 안내하는 **저승의 길잡이**가 됨 (바리데기 신화와 겹침). 이름 "무영(그림자가 없다)" = 이승에 속하지 않은 자.
  - 플레이어가 어떤 직업이든 "스승과 아들"의 비극을 옆에서 보는 구조 → 고정 주인공일 때의 감정선을 유지.
- **스승**: 주묵 수장이자 **모든 대원의 스승**, 최종 보스. 부적의 진실과 임박한 재앙을 알게 되어, 주묵의 힘의 근원을 끊고 **대귀문을 열어 쌓인 혼들을 윤회로 돌려보내려** 한다. 이승이 피를 흘리더라도. 악당이 아니라 **너무 많은 것을 알게 된 사람**.
  - 그날 밤 주인공에게 쥐여 준 부적은 **스승 자신의 혼으로 만든 봉인 부적** — 남의 혼이 아니라 자기 혼을 태운 마지막 속죄이자, **자신을 막을 사람**을 남겨 둔 것. "네가 나를 막는다면… 내가 틀렸던 것이겠지."
- **대사형**: 주묵 대원들의 큰 선배. 귀신에 씌어 2막 보스가 됨.

### 메인 스토리 (3막)

- **프롤로그 — 문이 열린 밤**: 월식의 밤, 대귀문이 열리고 주묵이 하룻밤에 몰살. 주인공(고른 직업 갈래의 막내)과 무영만 살아남음. 주인공의 손에는 죽어 가던 스승이 쥐여 준 부적 한 장 → 망자의 목소리가 들리기 시작. → 튜토리얼 (이동·공격·직업 기본 스킬)
- **1막 — 산군의 숲** (무너진 본산 → 산 아래 마을 → 숲 깊은 곳, 지역 13개 — 아래 "1막 지역 & 귀신" 참고)
  - 1막 초반에 귀신에게 점령된 산 아래 마을을 되찾음 → **거점 마을**이 됨.
  - 보스: **산군(山君)** — 원래 산을 지키던 **산신의 사자(호랑이)**. 대귀문이 열린 밤 그 기운에 타락함. 부하로 **창귀(倀鬼)** (호랑이에게 먹힌 자의 혼, 한국 민담).
  - 산군은 문의 기운을 직접 느꼈기에 "안에서 열렸다"는 것을 앎. 1막 내내 창귀들이 "살려 달라"고 하는 목소리가 들림 → 3막 반전("부적은 혼을 태운 것")의 복선.
  - 산군을 쓰러뜨리면 창귀들이 풀려남. 그중 일부가 **산 아래 마을 사람들**이었음 → "마을 사람들의 한" 서브 퀘스트로 이어짐.
  - 반전: "문은 부서진 게 아니다. **안에서 열렸다.**" → 배신자가 있다.
  - 클리어 시 인스턴스 던전 "귀문 균열" 해금.
- **2막 — 물귀신의 강** (강으로 가는 고갯길 → 황포 나루 → 수몰된 사찰, 지역 13개 — 아래 "2막 지역 & 귀신" 참고)
  - 2막 거점 **황포 나루**(뱃사람 마을)에서 "주묵의 도포를 입은 자를 상류에서 봤다"는 소문을 듣고 강을 거슬러 올라감. 무영도 황포 나루로 옮겨 옴.
  - 살아남은 동료를 찾지만, 찾아낸 대사형은 이미 귀신에 씌어 있음.
  - 물귀신들이 "춥다…", "꺼내 줘…"라고 말함 → 1막 "살려 달라"에서 이어지는 복선.
  - 보스: **타락한 대사형** — 주묵 세 갈래(부적·검·신내림)의 기술을 모두 쓰는 보스. 어떤 직업으로 하든 "내 갈래의 기술"과 마주치는 거울 같은 전투.
  - 반전: 처치 후 정신을 차린 대사형이 "문을 연 건… **스승님**이다."라고 말하고 숨을 거둠 → 옆에 있던 **무영이 무너지는 장면**으로 2막 끝.
- **3막 — 저승 경계** (경계가 무너진 들판 → 일주문 야영지 → 다시 찾은 본산 → 봉혼고 → 대귀문 너머, 지역 13개 — 아래 "3막 지역 & 귀신" 참고)
  - 1막의 무너진 본산으로 돌아오는 **수미상관 구조**. 저승 깊은 곳(지옥, 시왕)은 DLC 1을 위해 아끼고, 3막은 **이승과 저승의 경계까지만**.
  - 반전 (봉혼고): 쇠사슬에 묶여 부적으로 태워지는 혼들을 직접 봄 → "**부적은 혼을 태운 것이다.**" — 붉은 먹(주사)에 태운 혼의 재가 섞여 있었음 → 주묵 전체가 죄인이었다. (그 전 지역 **주묵 서고**에서는 검은 먹으로 지워진 기록들을 발견 → 반전 복선) **어떤 직업이든 자기 갈래가 연루됨**:
    - 부적사: 부적 자체가 혼을 태운 것
    - 퇴마검사: 검에 새긴 부적 문양이 혼을 태워 날을 세운 것
    - 무당: 몸에 내린 "신"이 사실은 갇혀 있던 혼
  - 스승의 뜻을 이해해 버린 무영이 스승 편에 설지 고민 → 최종전 중간에 무영을 붙잡음.
  - 최종 보스: **스승** (2페이즈, 아래 "3막 지역 & 귀신" 참고).
  - 결말: 아래 **"결말"** 참고.
- **DLC 1 — 4막 "저승"** (출시 후): 쿠키 장면의 "누군가 윤회의 길을 막고 있어"에서 이어짐. 저승으로 들어가 윤회가 멈춘 진짜 원인을 밝히고 **무영을 찾음** (예: 저승 시왕 중 하나의 타락). 신규 직업 **승병**.

### 결말

- **하나의 정식 결말**로 고정 (1인 개발 범위) + 서브 퀘스트 완성도에 따른 추가 장면.
- **① 봉인 부적의 진실**: 쓰러진 스승이 밝힘 — 그날 밤 쥐여 준 부적은 **스승 자신의 혼으로 만든 봉인 부적**. 남의 혼이 아니라 자기 혼을 태운 수장의 마지막 속죄. 스승은 처음부터 **자신을 막을 사람**을 남겨 두었음. 주인공이 망자의 목소리를 들을 수 있었던 것도 부적 안에 스승의 혼이 있었기 때문.
  > "네가 나를 막는다면… 내가 틀렸던 것이겠지."
- **② 무영의 선택**: 대귀문은 봉인해야 하지만 문 너머에 쌓인 혼들은 남음. 망자의 목소리를 듣는 무영이 **스스로 문 너머에 남아**, 쌓인 혼들을 하나씩 윤회로 안내하는 **저승의 길잡이**가 됨.
  - 한국 신화의 **바리데기**(죽은 자를 저승으로 인도하는 무조신)와 겹침.
  - 스승의 방식(문을 열어 한꺼번에 돌려보냄)도, 주묵의 방식(가둬서 태움)도 아닌 **제3의 길**.
- **③ 에필로그 — 새로운 주묵**: 주묵은 **혼을 태우지 않는 도술**로 다시 세워짐. 그 힘은 자신의 **기력(氣力)**에서 나옴 → 게임의 기력(MP) 시스템이 세계관 안에서 의미를 가짐.
- **④ 추가 장면 (서브 퀘스트)**: **동료 원혼 퀘스트를 모두 완료**하면 스승의 과거 회상 장면 추가 — 스승이 처음 진실을 알게 된 밤, 대원들과 싸우게 된 이유. "메인만 하면 배신자, 서브까지 하면 비극의 인물"이 완성됨.
- **⑤ 쿠키 장면 → DLC 1**: 크레딧 뒤 문 너머에서 무영의 목소리.
  > "저승이… 이상해. 혼들이 길을 못 찾는 게 아니야. 누군가 윤회의 길을 막고 있어."
  - 윤회가 멈춘 진짜 원인이 주묵만은 아니었다는 암시 → **DLC 1 "저승"** (4막, 시왕의 타락, 승병, 무영 찾기).

**두루마리 컷신 목록**


| 컷신              | 내용                             | 그림 수     |
| --------------- | ------------------------------ | -------- |
| 프롤로그            | 월식의 밤, 대귀문이 열림, 주묵의 몰살, 스승의 부적 | 6~8      |
| 1막 → 2막         | 산군의 말, 강을 향해 떠남                | 4~5      |
| 2막 → 3막         | 대사형의 죽음, 무너지는 무영               | 4~5      |
| 엔딩              | 봉인, 무영의 선택, 새로운 주묵             | 6~8      |
| 스승의 회상 (동료 6/6) | 스승이 진실을 알게 된 밤                 | 4~5      |
| 쿠키              | 문 너머 무영의 목소리                   | 1~2      |
| 합계              |                                | 약 25~33장 |


- **편의**: 모든 컷신·대화 **건너뛰기** 가능, 대화는 클릭하면 바로 다음 줄. 본 컷신은 메뉴의 **"두루마리 서고"**에서 다시 보기. 스토리 스킵 캐릭터는 컷신 없음.
- **그림 작업량**: 초상화 약 40장 + 두루마리 그림 약 25~33장 = **약 65~75장**. 결과를 크게 좌우하므로 **외주 수묵 일러스트레이터**에게 묶어서 의뢰 권장 (스타일 통일). 개발 중에는 **임시 그림**(AI·간단한 스케치)으로 자리를 잡고 **출시 전 정식 그림으로 교체** (AI 그림은 Steam 공개 대상, 핵심 그림은 사람이 그린 것 권장).
- **데이터 (Cursor 작업용 메모)**: `DialogueData` (ScriptableObject: 대사 줄 목록 — 줄마다 화자, 초상화·표정, 대사 키, 선택적 이벤트(퀘스트 진행, 카메라 연출 시작)) / `ScrollCutsceneData` (장면 목록 — 장면마다 그림, 움직임, 자막 키, 음성). 대사·자막은 모두 String Table.
