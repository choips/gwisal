### 한 줄 컨셉

**저승문이 열린 밤 몰살당한 비밀 퇴마 집단 "주묵(朱墨)"의 마지막 생존자가, 자신의 갈래(직업)의 도술로 귀신을 베며 문을 연 배신자와 그 뒤에 숨은 진실을 쫓는 스토리 중심 핵앤슬래시.**

### 범위 원칙 (1인 개발)

- 출시 범위: 메인 스토리 **3막** + 초기 직업 **3종**. 그 이상은 DLC로.
- 서브 퀘스트·인스턴스 던전은 **메인 지역의 맵과 귀신을 재활용**. 새로 만드는 건 대사·소품 위주.
- 버티컬 슬라이스는 **부적사 하나로만** 만든다 (지금 만든 전투가 부적사 전투). 퇴마검사·무당은 출시 전에 **하나씩** 추가.
- 시스템은 **콘텐츠가 요구할 때** 만든다. "있으면 좋은 기능"은 뒤로 미룸.

### 차별점 원칙 — "디아블로 카피"로 보이지 않게 (2026-10-14)

- 지역·웨이포인트·아이템 등급·스킬 트리 같은 **장르의 틀은 그대로** 둠 (PoE·그림 던·라스트 에포크도 같음). 카피 소리는 ① **스크린샷·첫 10분이 디아블로처럼 보일 때**, ② **이 게임만의 대표 시스템이 없을 때** 나옴.
- **① 화면에서 디아블로 흔적 지우기 (채택)**

| 디아블로와 같던 것 | 귀살에서는 |
| --- | --- |
| 체력·기력 둥근 구슬 두 개 | 체력 = **먹 단지**, 기력 = **벼루의 먹물**이 차오르는 모양 (최종 모양은 HUD 그림 작업 때 — 두루마리 한 줄도 후보) |
| 아이템 색 흰·파랑·노랑·주황·초록 | **한지(노멀) → 쪽빛(매직) → 황토(레어) → 주사 붉은색(유니크) → 금박(세트)** + 등급마다 **낙관(도장)** 모양 (`03` "등급 5종") |
| "귀문 균열" (디아블로 3·4 "균열"과 같은 이름) | **이름 바꿈** — 후보 "귀문 틈"·"저승 문턱", 엔드게임 작업 전에 확정 (그때까지 문서는 "귀문 균열"로 둠) |
| 격자 인벤토리 | 격자는 두되 겉모습을 **보따리·부적첩**으로 |
| 귀환 = 포탈 | **축지법으로 마을까지** + 먹 번짐 연출 |

- **② 대표 시스템 → 확정 (2026-10-15): 망자의 호패 & 혼백첩** — 귀신이 떨어뜨리는 **호패**(귀신의 혼)를 끼우고 **풀어 주며**, **유니크를 태워** 고유 효과를 혼 부적으로 모음. 세부는 `03_아이템_능력치_경제.md` "망자의 호패 & 혼백첩".
  - 고를 때 기준: 조선의 설화·풍속·물건과 연결된 핵심 콘텐츠 하나. 후보 — (망자의 호패는 위처럼 개발 예정으로 따로 뺌) 나례와 방상씨 탈(탈 모으기·각성), 대동여지도 지맥(정화한 지역이 이어지며 성장), 때를 맞춘 부적(단오부·사인검 — 열두 시각), 원혼의 신원(아랑·장화홍련), 지워진 사초 복원, 도깨비와의 거래. 실존 왕·정치 사건·일제강점기 소재·붓으로 그리는 조작(오카미와 겹침)은 피함.
  - **2차 후보 (2026-10-15)**: 다른 핵앤슬래시의 호평 콘텐츠를 바꾼 **A 손 있는 날 · B 사십구재 저승길(DLC 1과 함께) · C 먹 안개 · G 혼 담는 부적첩 · J 칠성단 별자리** → 아래 "대표 시스템 후보 상세".

### 대표 시스템 후보 상세 (2026-10-15 — G는 확정, A·B·C·J는 콘텐츠 후보)

> 다른 핵앤슬래시(디아블로 2·3·4, PoE, 라스트 에포크, 그림 던)에서 호평받은 시즌·핵심 콘텐츠를 귀살에 맞게 바꾼 후보. 처음 10개 중 사용자가 **A·B·C·G·J**를 남김. 수치는 모두 초안 — 정하면 밸런스 엑셀로 옮김.
> 뺀 후보(참고): 멈춘 그날 밤(PoE Legion), 주묵 재건(Incursion), 타락한 주묵 명부(Betrayal), 두 갈래 서약(라스트 에포크 세력), 지관의 흉당 끊기(Expedition — 쇠말뚝은 일제강점기 소재라 쓰지 않음).

**A. 손 있는 날** — 원본: 디아블로 2 레저렉션 "공포의 영역", 디아블로 4 지옥물결 (지나온 지역을 다시 찾을 이유)
- 민속: "손"은 날마다 방위를 옮기는 귀신. 음력 끝자리 1·2일 동, 3·4일 남, 5·6일 서, 7·8일 북, **9·10일은 손 없는 날** (이삿날 고르는 풍습).
- 규칙: 게임 속 하루 = **플레이 20분**(게임을 켜 둔 시간만 셈), 10일 주기. 막마다 지역 13개를 거점 기준 동·서·남·북으로 나눔 → 손 든 방위의 지역이 **"손 든 지역"**.
- 손 든 지역: 귀신 레벨 = 플레이어 레벨 +2(지역 레벨보다 낮으면), 정예 수식어 +1, 경험치·매직 이상 드랍 ×1.5, 떠돌이 정예 **"손"** 1마리(처치 → 손 주머니 = 등급 보장 상자).
- 손 없는 날(9·10일): 손 든 지역 없음 → 모든 지역 엽전 +25%, 보부상 품목 갱신 무료 ("길일").
- 표시: 지도·웨이포인트 창에 손의 방위(나침반 바늘), HUD 위쪽에 "○일 · 동쪽에 손".
- 열림: **1막 보스(산군) 처치 후**. 흉몽·말세에서도 그대로.
- 연결: 방 의뢰("손 든 지역에서 정예 10마리"), 호패(손 든 지역에서 호패 확률 ↑).
- 만들 것: 게임 속 날짜 시계(세이브), 지역 강화 데이터, 지도·HUD 표시, "손" 정예 1종. **작음.**

**B. 사십구재 저승길** — 원본: 디아블로 4 지옥 군단(웨이브 + 축복/대가 고르기, 기본 게임에 들어감), PoE Ultimatum
- **DLC 1(4막 "저승" + 승병)과 함께 개발·출시** (사용자 결정 2026-10-15). 4막 저승 타일·귀신을 그대로 씀. 기본 게임 엔드게임은 귀문 균열 그대로.
- 민속: 죽은 뒤 7일마다 시왕에게 심판받는 사십구재 (진광·초강·송제·오관·염라·변성·태산대왕). 「신과 함께」 덕분에 친숙 — 단 그 작품의 인물·설정은 쓰지 않음.
- 흐름: 거점 **저승길 입구**(DLC NPC) → 7재(초재~칠재) 원형 경기장, 재마다 다른 지옥 (도산·화탕·한빙·검수·발설·독사·거해) → 한 재 = **90초 귀신 웨이브** → 끝나면 **심판**: 업(業) 카드 3장 중 1장 (축복 + 대가, 예: "피해 +30% / 물약 충전 −1") → 칠재 끝에 **태산대왕**(보스).
- 보상: 웨이브에서 **넋**을 모음 → 끝나면 **업경대(業鏡臺) 저울**에서 넋으로 상자 고르기 (무기·방어구·장신구·호패 상자). 죽으면 그때까지 모은 넋의 절반으로 저울.
- 확장: 단계(1~10) 선택 + 칠재 뒤 고난도 3재(백일재·소상·대상 — 평등·도시·전륜대왕)는 선택.
- 연결: 결말(무영이 혼을 윤회로 이끔), DLC 1 쿠키 장면, 호패(시왕 호패 — 특별 호패).
- 만들 것: 경기장 7개(저승 타일 재활용), 업 카드 약 30장, 웨이브 표(지금 무한 스포너 재활용), 대왕 보스 1(태산), 저울 UI. **중간** — DLC 작업량에 포함.

**C. 먹 안개 (어둑시니의 꿈)** — 원본: PoE Delirium·Breach (깊이 들어갈수록 위험·보상 증가, 둘 다 기본 게임에 들어감)
- 발동: 1막 이후 지역·균열에 가끔 **꿈 항아리**(지역당 0~1개, 확률 약 25%). 깨면 화면 가장자리부터 **먹물이 번지며** 안개가 지역에 퍼짐.
- 안개 안: 시간이 지날수록 **어둠 단계**(1~10)가 오름 → 귀신 피해·체력 단계당 +8%, 그림자 귀신 추가 생성, 대신 **꿈 조각**(경험치·드랍 보너스)이 단계마다 쌓임.
- 끝: 기본 60초 + 귀신 처치마다 +1초. 시간이 끝나거나 **항아리 자리로 돌아가 "깨어나기"**를 누르면 꿈 조각 정산(상자). 안개 속에서 죽으면 조각 절반.
- 어둠 단계 5·10에서 **어둑시니 본체**(정예): 마우스 커서를 올려 두면(=쳐다보면) 커지고 강해짐 → 커서를 비켜서 범위 스킬로 잡는 이 게임만의 기믹.
- 아트: 화면 가장자리 먹 번짐(후처리 비네트) + 바닥 먹 무늬. 스크린샷만 봐도 다른 게임 → 차별점 원칙 ①. **최소 사양 30fps 확인 필요.**
- 열림: 1막 완성 후(슬라이스 다음). 귀문 균열 변형("어둠")과 말세에서 더 자주.
- 만들 것: 항아리 오브젝트, 안개 퍼짐·어둠 단계 관리자, 화면 효과, 어둑시니 커서 기믹, 정산 상자. **중간~작음.**

**G. 혼 담는 부적첩 → "혼백첩"으로 확정 (2026-10-15, 호패와 묶어 대표 시스템, 세부는 `03`)** — 원본: 디아블로 3 카나이의 함, 디아블로 4 위상 코덱스 (고유 효과를 모아 빌드를 짬)
- 거점의 부적첩(무영에게서 받음)에 **유니크 아이템을 태워** 그 고유 효과를 **혼 부적**으로 영구 등록 (아이템은 사라짐, 처음 한 번만, 같은 효과는 더 높은 수치로 덮어씀).
- 칸 3개: **무기 혼·몸 혼·장신구 혼**에 하나씩 켬. 거점에서 바꾸기 무료.
- 수치: 혼 부적은 **원래 아이템의 최솟값** (진짜 아이템을 끼는 의미가 남게). 등록 비용 = 엽전 + 주사(재료).
- 세트 효과는 못 넣음. 동료의 유품(퀘스트 유니크)은 넣을 수 있음.
- 연결: **3막 반전("부적은 혼을 태운 것")** — 반전 뒤 무영의 대사가 바뀜 ("…우리도 혼을 태우고 있었던 거네."). 호패와 같은 책 UI(호패 쪽 / 혼 부적 쪽 두 탭).
- 열림: 첫 유니크를 얻은 뒤(1막 중). 유니크 36개가 다 생기면 빌드 폭이 커짐.
- 미리 챙길 것: 유니크 고유 효과를 아이템과 **따로 떼어 낸 효과 데이터**로 만들어 두면 이 시스템은 거의 공짜 (채택되면 전달 사항으로).
- 만들 것: 부적첩 창, 효과 등록·켜기, 저장. **작음.**

**J. 칠성단 별자리** — 원본: 그림 던 헌신(별자리를 이어 가며 성장), 라스트 에포크 운명의 모노리스 거미줄 (참고)
- **도력(06 엔드게임)의 겉모습으로 씀** — 따로 만들지 않고 도력을 이 판으로 바꿈. 출시 후 업데이트로 미뤄도 됨(도력과 같음).
- 레벨 50 이후 경험치 → 도력 점수. 거점 **칠성단**에서 별자리 판에 찍음. 판 배경은 **천상열차분야지도**(조선 천문도, 만 원권 뒷면).
- 판: 사방 **사신 28수** = 4갈래 × 7별 — 청룡(공격 속도·이동), 주작(원소 피해), 백호(체력·방어), 현무(저항·회복). 가운데 **북두칠성** 7별(탐랑·거문·녹존·문곡·염정·무곡·파군) = 강한 효과(예: 파군 — 처치 시 폭발), 사신 갈래에 일정 수 이상 찍어야 열림.
- 총 100점(도력 100단계)로 판 전체를 다 찍을 수 없게 → 고르는 재미. 초기화 무료(거점).
- 만들 것: 노드 판 UI, 효과 약 35개, 저장. **중간.**

4. 인스턴스 던전 1종 (슬라이스의 귀신·보스 재활용)
5. 2막·3막, 서브 퀘스트, 인던 확장, 엔딩

8. DLC: 4막 "저승" + 승병, 이후 막·직업 추가 — **초기 버전(3막 + 직업 3종) 개발·출시가 끝난 뒤에 기획·개발 시작** (그 전까지는 지금 정해 둔 방향만 유지: 3막 쿠키 장면, 승병, 4막 "저승")
