# 슬라이스 플레이테스트 체크리스트 (개발자 직접)

> 2026-10-14 작성. S7 "처음부터 보스까지 직접 플레이하며 밸런스 조정" 때 사용합니다.
> 외부 테스트는 하지 않고 개발자가 직접 합니다 (외부 테스트는 데모 공개 전으로 미룸).
> 기준은 `Docs/기획/07_아트_성능_모바일_출시.md` → "슬라이스 마무리 상세 (S7)".

## 사용법
- **새 캐릭터로 처음부터** 한 판을 끝까지 합니다 (개발자 UI의 무적·레벨 조정은 쓰지 않음).
- 한 판이 끝나면 아래 "판별 기록" 표에 한 줄 적습니다. 숫자는 클리어 화면과 `playlog.txt`(세이브 폴더)에서 옮깁니다.
- **안 되는 항목**은 체크하지 말고 바로 아래에 `→ 문제: (무슨 일이 있었는지)`를 적어 둡니다. 다 끝난 뒤 문제 목록을 Cursor에게 한꺼번에 보여 줍니다.
- 표시: ⭐ = 꼭 확인할 핵심 항목

---

## 0. 준비
- [ ] Console(**Ctrl + Shift + C**) → **Clear** → ⭐ **빨간 오류 0개**, **Error Pause** 켜기
- [ ] 세이브 폴더 백업 (`%USERPROFILE%\AppData\LocalLow\DefaultCompany\귀살`)
- [ ] 1판은 품질 **높음**, 1판은 **최소 사양 흉내**(품질 낮음 + 렌더 스케일 0.7)로

## 1. 화면 흐름
- [ ] 첫 실행: 품질이 자동으로 추천됨 (설정 → 그래픽에서 확인)
- [ ] 타이틀: 캐릭터가 없으면 [이어하기]가 회색
- [ ] 캐릭터 만들기: 부적사만 선택 가능, 퇴마검사·무당은 "준비 중"
- [ ] 이름: 빈 이름·13자 이상·이미 있는 이름은 거절됨
- [ ] 캐릭터 선택: 이름·직업·레벨·지역이 보임, 삭제는 이름을 입력해야 됨
- [ ] ⭐ 타이틀 [이어하기] → 마지막 캐릭터의 마지막 지역에서 시작

## 2. 플레이 (구간별 목표)
| 구간 | 목표 시간 | 끝날 때 레벨 | 확인 |
| --- | --- | --- | --- |
| 컷신 + 무너진 본산 | 1 + 3분 | 2 | ☐ |
| 백팔 계단 | 3분 | 4 | ☐ |
| 안개 산길 | 4분 | 5 | ☐ |
| 산 아래 마을 | 3분 | ⭐ 6 | ☐ |
| 산군의 굴 | 3분 (산군 1.5~2분) | 8 | ☐ |
| **합계** | ⭐ **15~20분** | | ☐ |

- [ ] 길을 잃지 않음 (다음에 어디로 갈지 알 수 있었음)
- [ ] 장비가 약 18개 떨어짐, 매직·레어가 섞여 있음, 산군 첫 처치 때 산군의 가죽
- [ ] 물약이 모자라거나 남아돌지 않음 (기운 구슬로 적당히 채워짐)
- [ ] 보부상에서 엽전으로 뭔가 살 수 있었음 (약 600엽전)

## 2-2. 스토리 흐름 (S4)
- [ ] 새 캐릭터: 두루마리 컷신 4장, 클릭 = 다음 자막, [건너뛰기] 동작 / 이어하기 때는 컷신 없음
- [ ] 대화창: 글자가 한 자씩, 클릭하면 줄 완성 → 다음 줄, 대화 중 게임 멈춤, 건너뛰어도 퀘스트가 진행됨
- [ ] ⭐ 튜토리얼 문구 4개가 직접 해낼 때마다 넘어감, 문구 속 키 이름이 실제 키와 같음
- [ ] ⭐ 퀘스트 추적기 목표가 대본 순서대로 바뀜 (본산 → 마을 → 산군), "남은 귀신 N"이 줄어듦
- [ ] 창귀 근처 "살려 줘…" 자막(흐릿한 회색), 장면 대사는 한 번만
- [ ] 미니맵에 탐험한 곳만 보임, Tab 겹쳐 보기 켜기/끄기, 게임이 안 멈춤
- [ ] 마을 탈환 → 무영 대화 자동 → 서낭당 활성화 → 보부상 [거래]: 사기·팔기·되사기
- [ ] 장승: 백팔 계단·안개 산길 입구를 지나면 활성화, 서낭당에서 순간이동
- [ ] ⭐ 산군 등장 연출(처음만) → 다시 들어가면 이름만 1초, 보스전 중 귀환 불가
- [ ] 반전 대화 → 무영 → 클리어 화면 (두 번째 처치 때는 없음)

## 2-3. 스킬 & 조작 (S5)
- [ ] ⭐ 레벨 1부터 부적 투사체(좌클릭)·부적 폭발(우클릭), 투사체 3번 → 폭발 1번 리듬
- [ ] 레벨업 → [+] 깜박 → 스킬 창(T)에서 배우기 → 빈 칸에 자동, 끌어놓기로 자리 바꾸기
- [ ] 레벨 5쯤 제웅이 열림, 산군 앞에서 5개 스킬 모두 사용 가능
- [ ] [초기화]로 포인트가 돌아옴 (투사체·폭발은 남음)
- [ ] 누르고 있으면 계속 시전, Shift = 제자리, 시전 중 누른 입력이 씹히지 않음

## 3. ESC 메뉴 · 사망 · 클리어
- [ ] ESC: 게임이 멈춤, [계속하기] [설정] [저장하고 타이틀로] [저장하고 종료]
- [ ] ⭐ 무작위 지역에서 죽기 → 엽전 5% 잃음, 같은 지도의 입구에서 부활, 체력·기력·물약 가득
- [ ] 산군에게 죽기 → 굴 입구 앞에서 부활, 산군 체력 가득
- [ ] 마을 탈환 뒤 죽기 → 서낭당에서 부활
- [ ] 본산·탈환 전 마을에서 죽기 → 잡은 귀신은 그대로 죽어 있음
- [ ] ⭐ 저장하고 종료 → 이어하기: 탈환 전 = 마지막 지역 입구, 탈환 후 = 마을 서낭당
- [ ] ⭐ 클리어 화면: 문구 + 기록 5개 + [마을로 돌아가기] [타이틀로]
- [ ] [마을로 돌아가기] → 마을에서 계속 플레이 가능

## 4. 설정 · 소리 · 성능
- [ ] 품질 낮음/중간/높음을 바꾸면 바로 반영, 게임을 다시 켜도 유지
- [ ] 볼륨 3개(전체·음악·효과음)가 동작하고 유지됨
- [ ] 음악 3곡(필드·마을·보스)이 지역·보스전에 맞게 바뀜, 환경음이 깔림
- [ ] 지역 이동 때 먹빛 화면 + 붓글씨 지역 이름, 도착하자마자 맞지 않음
- [ ] 효과음 12개가 모두 남, 귀신 떼를 한 번에 잡아도 소리가 터지지 않음
- [ ] ⭐ 최소 사양 흉내에서 귀신이 가장 많은 장면(안개 산길 창귀 무리, 산군 2페이즈)도 **30fps 이상** (개발자 UI 또는 Stats 창)

## 문제가 있을 때
- 문제 목록과 판별 기록 표를 Cursor에게 보여 주고 "원인 설명 → 수정 순서 제안"을 부탁합니다.
