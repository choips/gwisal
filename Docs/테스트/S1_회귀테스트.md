# S1 회귀 테스트 체크리스트

> 2026-10-14 작성. **회귀 테스트** = 새 기능을 넣은 뒤, 예전에 되던 기능이 여전히 되는지 처음부터 다시 확인하는 것.
> S1에서 입력·스킬·풀링·능력치·아이템·세이브·씬 구조를 한꺼번에 바꿨기 때문에, **S2로 넘어가기 전에 한 번** 끝까지 해 봅니다.
> 소요 시간: 약 40~60분. 한 번에 다 못 하면 섹션 단위로 나눠서 해도 됩니다.
>
> **결과 (2026-10-18)**: 섹션 0~13 통과. 회귀 중 F1 메뉴 스크롤 수정. 참고 — 2번 휠 줌은 [전달-21]로 없음이 정상, 4번 맵 전멸 후 새 적은 안 나옴이 정상(고정 배치).

## 사용법
- 항목을 하나씩 해 보고, 되면 `- [ ]`를 `- [x]`로 바꿉니다.
- **안 되는 항목**은 체크하지 말고 바로 아래에 `→ 문제: (무슨 일이 있었는지)`를 적어 둡니다.
  다 끝난 뒤 문제 목록을 Cursor에게 한꺼번에 보여 주면 됩니다 (맨 아래 "문제가 있을 때" 참고).
- 표시: ⭐ = 꼭 확인할 핵심 항목, 🎮 = 게임패드가 있을 때만

## 0. 준비
- [ ] Cursor 터미널에서 `git status` → `working tree clean` (테스트 전 상태를 깨끗하게)
- [ ] Unity를 열고 Console(**Ctrl + Shift + C**) → **Clear** → ⭐ **빨간 오류 0개**
- [ ] Console 위쪽의 **Error Pause**를 켜 둠 (테스트 중 오류가 나면 게임이 바로 멈춰서 놓치지 않음)
- [ ] **세이브 파일 백업**: `%USERPROFILE%\AppData\LocalLow\DefaultCompany\귀살` 폴더를 통째로 다른 곳에 복사해 둠
  (탐색기 주소창에 위 경로를 붙여 넣으면 열림)
- [ ] 백업한 뒤 그 폴더의 파일을 **모두 지움** → 새 게임 상태에서 시작

## 1. 시작과 씬 구조 (S1-10)
- [ ] ⭐ `Core` 씬을 열고 ▶ Play → 화면이 밝아지며 시작 지역(`Region_01`)이 나타남
- [ ] 도착할 때 화면 가운데에 **지역 이름**이 크게 나왔다가 사라짐
- [ ] Hierarchy에 `Core`와 `Region_01` 두 씬이 함께 보임
- [ ] Play를 멈추고 `Region_01` 씬을 연 상태에서 ▶ Play → 그래도 **Core로 시작**해 정상 동작
- [ ] Console에 빨간 오류 없음

## 2. 기본 조작 — 키보드·마우스 (S1-2)
- [ ] ⭐ 바닥 **좌클릭** → 그 자리로 이동, 클릭 위치에 하늘색 동그라미 표시
- [ ] 좌클릭을 **누르고 있으면** 커서를 따라 계속 이동
- [ ] 마우스 **휠** → 카메라 확대/축소, 카메라가 플레이어를 부드럽게 따라옴
- [ ] **I** → 인벤토리 열기/닫기
- [ ] 인벤토리 창 위를 클릭했을 때 캐릭터가 그쪽으로 걸어가지 **않음** (UI 클릭이 바닥 클릭으로 새지 않음)

## 3. 전투와 스킬 (S1-2·S1-3·S1-6)
- [ ] ⭐ 적 **좌클릭** → 다가가서 사거리 안에서 멈추고 공격, 데미지 숫자가 튀어 오름
- [ ] 가끔 **치명타** (크고 빨간 숫자 + "!")가 나옴
- [ ] 맞은 적이 하얗게 **번쩍이고 뒤로 밀림** (넉백)
- [ ] ⭐ **우클릭** → 부적 투사체 발사, 맞은 적에게 데미지 + 금색 불꽃
- [ ] 부적이 **키 작은 적**(아귀·잡귀)도 통과하지 않고 맞힘
- [ ] ⭐ **Q 누르고 있기** → 조준 원(금색), 기력이 모자라면 빨간색 / **떼기** → 부적 폭발, 범위 안 적 모두 데미지
- [ ] Q 조준 중 **ESC** → 조준 취소, 폭발 안 함, 기력 안 씀
- [ ] 스킬바: 쿨타임 동안 칸에 **원형 덮개 + 남은 시간**, 기력이 모자라면 칸이 **어두워짐**
- [ ] 기력이 시간이 지나며 **자연 회복**됨
- [ ] **1** → 기력 물약 마심 (물약 칸 숫자 감소, 0개면 칸이 어두워짐)

## 4. 적 AI·몬스터 무리·풀링 (무리 배치·S1-7·S1-11)
- [ ] ⭐ 적에게 가까이 가면 쫓아와서 공격, 플레이어 데미지 숫자는 **보라색**
- [ ] 적 머리 위 **체력바**: 맞기 전엔 숨어 있다가 맞으면 나타남
- [ ] 적이 **바닥에 묻히지 않고** 발이 바닥에 닿아 있음
- [ ] **챔피언·유니크·하수인** 등급 적이 색·크기·이름표로 구분됨
- [ ] 적이 플레이어 **바로 옆에서 갑자기 생기지 않음**
- [ ] ⭐ 적을 많이 잡은 뒤 새로 나온 적도 **체력이 가득**하고 정상적으로 싸움 (풀에서 재사용된 적이 이전 상태를 끌고 오지 않음)
- [ ] 이미 죽은 적을 계속 공격하거나 쫓아가지 않음 (타겟이 풀로 돌아간 경우)

## 5. 성장과 능력치 (S1-6)
- [ ] ⭐ 적 처치 → **경험치** 바 증가, 가득 차면 **레벨 업** 알림, 레벨 숫자 증가
- [ ] 레벨 업 후 **최대 체력·기력**이 늘어남
- [ ] **방어구**를 끼면 받는 데미지가 줄어듦 (같은 적에게 맞는 보라색 숫자가 작아짐)
- [ ] 체력이 0이 되면 **"YOU DIED"** 화면 → 부활 버튼 → 시작 위치에서 부활, 2초 무적(깜빡임)

## 6. 아이템과 인벤토리 (S1-9)
- [ ] ⭐ 적 처치 → 아이템이 튀어 올라 떨어지고, 바닥에 **등급 색 이름표**
- [ ] 이름표에 등급(예: [레어])과 아이템 이름이 **한글로** 제대로 보임 (□로 깨지지 않음)
- [ ] 아이템 **클릭** → 걸어가서 주움, 가방 칸에 **아이콘 + 등급 색 테두리**
- [ ] 아이템 **마우스 올리기** → 툴팁에 능력치, **장착 장비와 비교**(▲초록 / ▼빨강)
- [ ] 무기·방어구 **장착** → 장비 칸에 아이콘, 능력치 반영 / 장비 칸 클릭 → **해제**되어 가방으로
- [ ] 기력 물약은 가방에서 **묶음(×N)**으로 표시
- [ ] 가방이 **가득 차면** 줍기·해제가 안 되고 알림이 뜸

## 7. 지역 이동 (S1-10)
- [ ] ⭐ 지역 **출구**로 가면 화면이 어두워졌다가 `Region_02`로 이동, 지역 이름 표시
- [ ] 이동한 뒤에도 **체력·기력·레벨·경험치·가방·장비가 그대로**
- [ ] `Region_02`에서 다시 출구로 → `Region_01`로 돌아옴
- [ ] 지역을 오간 뒤에도 적이 정상적으로 나오고 싸움 (떠난 지역의 적이 따라오거나 남지 않음)
- [ ] 이동 중(화면이 어두운 동안) 클릭해도 캐릭터가 엉뚱하게 움직이지 않음

## 8. 저장과 불러오기 (S1-9)
- [ ] ⭐ 레벨을 조금 올리고 장비를 낀 상태에서 **S** → "저장" 알림
- [ ] 세이브 폴더에 `Character_0.json`과 `Account.json`이 생김
- [ ] 체력을 깎이거나 아이템을 버린 뒤 **L** → 저장했던 상태로 돌아옴 (레벨·경험치·체력·기력·가방·장비)
- [ ] 불러온 장비의 **아이콘·이름·능력치**가 그대로
- [ ] 죽은 상태("YOU DIED")에서 **L** → 부활하며 불러와짐
- [ ] (② 안전한 저장 적용 후) `.bak` 파일이 생김 / 세이브 파일을 일부러 망가뜨리면 `.bak`으로 복구되고 알림이 뜸
- [ ] (② 적용 후) `Region_02`에서 저장 → 불러오기 → `Region_02` 입구에서 시작
- [ ] (옛 세이브 확인, 선택) 0단계에서 백업해 둔 옛 `SaveData.json`만 폴더에 다시 넣고 **L** → 자동 변환되어 불러와짐

## 9. 화면 글자·번역 (S1-8)
- [ ] 알림(가방 가득·기력 부족·레벨 업·저장/불러오기 등)이 **모두 한글로** 제대로 나옴
- [ ] 툴팁, 아이템 종류·등급, 인벤토리, 레벨 표시, 귀신 이름·등급 이름표에 **키 이름**(예: `notice.save_done`)이 그대로 보이는 곳이 없음
- [ ] 글자가 □로 깨지는 곳이 없음

## 10. 개발자 메뉴 (S1-5)
- [ ] **F1** → 왼쪽 위에 개발자 메뉴 창, 다시 F1 → 닫힘
- [ ] **무적** 켜기 → 맞아도 체력이 줄지 않음
- [ ] **기력 무한** 켜기 → 부적 폭발을 계속 써도 기력이 그대로
- [ ] **쿨타임 없음** 켜기 → 스킬을 연달아 쓸 수 있음
- [ ] **레벨 +1 / +5** → 레벨과 능력치가 오름
- [ ] **DPS 측정**: 적을 때리면 누적 피해·DPS가 나오고, 초기화 버튼으로 0이 됨
- [ ] 개발자 메뉴 창 위를 클릭해도 캐릭터가 이동하거나 스킬을 쓰지 않음
- [ ] (③ 로그 정리 적용 후) 전투 로그가 꺼진 상태에서 전투해도 Console이 조용함, F1에서 켜면 로그가 다시 나옴

## 11. 게임패드 🎮 (S1-2) — 게임패드가 있을 때만
- [ ] 🎮 **왼쪽 스틱** → 화면 기준 방향으로 이동, 놓으면 멈춤
- [ ] 🎮 **A** → 가까운 적 공격, 적이 없으면 가까운 아이템 줍기
- [ ] 🎮 **Y** → 부적 투사체, **B** → 부적 폭발 (가까운 적 **자동 조준**, 적이 없으면 앞쪽)
- [ ] 🎮 **십자 위** → 기력 물약, **Select** → 인벤토리
- [ ] 🎮 게임패드와 마우스를 번갈아 써도 둘 다 정상 동작

## 12. 오래 플레이하기 (풀링·성능)
- [ ] ⭐ **10분 이상** 계속 사냥 (지역도 2~3번 오가기)
- [ ] 시간이 지나도 **끊김이 심해지지 않음**
- [ ] Hierarchy의 `DontDestroyOnLoad` → `[ObjectPool]` 아래 오브젝트 수가 **끝없이 늘어나지 않음**
  (사냥하는 동안 늘었다가, 쉬는 것들은 `Storage` 아래로 모임)
- [ ] (선택) Game 창 오른쪽 위 **Stats** 버튼 → FPS가 크게 떨어지지 않음
- [ ] 테스트 내내 Console에 ⭐ **빨간 오류 0개**

## 13. 마무리
- [ ] Play를 멈추고 Console 다시 확인 → 멈추는 순간 생긴 오류도 없음
- [ ] 0단계에서 백업한 세이브 폴더를 원래 자리로 되돌림 (필요하면)
- [ ] 결과를 `개발현황.md` 변경 이력에 한 줄 기록 (예: "S1 회귀 테스트 통과" 또는 "S1 회귀 테스트: 문제 N개 발견")

## 문제가 있을 때
안 되는 항목을 모아 Cursor에게 아래처럼 보내세요.

```
S1 회귀 테스트를 했고, 아래 항목에서 문제가 있었습니다.
원인을 먼저 하나씩 설명하고, 고치는 순서를 제안해 주세요. 코드는 제가 확인한 뒤 수정해 주세요.
기존에 동작하는 기능은 그대로 유지해야 합니다.

[체크리스트 번호와 항목]
→ 문제: [무슨 일이 있었는지, 몇 번 해 봤는지, 항상 그런지 가끔 그런지]
[Console 오류가 있었다면 오류 메시지 전체]
```

- 문제를 적을 때 **"어떻게 하면 다시 생기는지"**(예: "지역을 두 번 오간 뒤 적을 잡으면")를 함께 적으면 고치기가 훨씬 쉽습니다.
- 빨간 오류는 Console에서 클릭하면 아래에 자세한 내용이 나옵니다. 그 부분까지 통째로 복사해서 보여 주세요.
