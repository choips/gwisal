### 지역 구성 방식 (디아블로 2식)

- **액트당 지역 10개 이상** (오픈월드는 아님). 3막 기준 30개 이상.
- **타일셋 + 무작위 생성**: 지형 조각 세트(타일셋)를 만들어 두고, 지역에 들어갈 때마다 무작위로 조립. 같은 타일셋을 여러 지역이 공유.
- **수작업 맵은 소수**: 거점 마을, 보스 방, 스토리 핵심 장소만 직접 만듦.
- **무작위 맵 생성기 하나로 스토리 지역과 귀문 균열(인던)을 함께** 만듦. 2회차 이후 파밍도 매번 지형이 바뀜.
- **웨이포인트 = 서낭당·장승** (지역 간 순간이동 지점).
- **이름 있는 정예 귀신**: 지역마다 하나씩 (디아블로 2의 슈퍼 유니크 몬스터). 파밍 목표 지점.
- **귀신은 계열 + 변종**: 같은 모델에 색·능력만 바꾼 변종으로 종류를 늘림.
- **그래픽**: 직접 모델링보다 **에셋 스토어의 동양풍 팩**(사찰, 한옥, 숲, 동굴)을 사서 타일셋으로 활용.
- 무한 스폰 스포너(지금 만든 것)는 **귀문 균열용**. 스토리 지역은 **정해진 위치에 귀신 배치**.

### 지역 레벨 표

**기준**

- **최대 플레이어 레벨 50**. 메인 스토리 엔딩 시점 플레이어 레벨 **약 33~35** → 궁극 스킬(23포인트, 레벨 24)은 3막 초반, 핵심 지속 효과(33포인트, 레벨 34)는 엔딩 무렵에 열림.
- 막 끝 예상 플레이어 레벨: 1막 ≈ 13 / 2막 ≈ 24 / 3막 ≈ 34
- 몬스터 레벨: 일반 = 지역 레벨 / 정예·이름 있는 정예·금 도깨비 = +2 / 보스·중간 보스 = +3
- 선택 던전은 주변 지역보다 1~2 높게 (보상도 더 좋음). 층이 있으면 아래층일수록 +1.
- 거점 마을은 안전 지역 (레벨 없음, 귀신 없음).

**귀문 균열 (반복 파밍)**

- 균열 **단계 n**의 지역 레벨 = **12 + 2n** (단계 1 = 14 … 단계 20 = 52) → 보스 몬스터 레벨 최대 55 = **최대 아이템 레벨 55**.
- 해금: 1막 클리어 → 단계 1~5 (14~22) / 2막 클리어 → 단계 6~10 (24~32) / 엔딩 → 단계 11~20 (34~52).
- 엔딩 후 만든 캐릭터(스토리 스킵)는 균열 단계 1부터 올라감.

**경험치 규칙 (재설계 필요)**

- 지금의 "필요 경험치 ×1.5" 곡선은 레벨 50까지 가면 숫자가 너무 커짐 → **완만한 곡선**으로 바꿈 (예: 다음 레벨 필요 경험치 = 100 × 레벨^1.5).
- 귀신 경험치는 **몬스터 레벨에 비례**.
- 플레이어보다 **5레벨 이상 낮은** 귀신은 경험치가 크게 줄어듦 (디아블로 2 방식) → 앞 지역에서 무한히 레벨업하는 것을 막음.

**버티컬 슬라이스 임시 레벨**: 슬라이스는 1막 앞부분만 있으므로 무너진 본산 1 → 백팔 계단 2 → 안개 산길 3 → 산 아래 마을(탈환 전) 4 → **산군의 굴 5** (슬라이스 전용, 정식 게임에선 13).

### 1막 전체 흐름 (① — 2026-10-14 확정)

> 1막 나머지 상세 기획의 첫 단계. 다음 단계: ~~② 새 귀신 상세~~ (2026-10-15 완료, 아래 "1막 새 귀신 상세") → ③ 동굴·고분 타일셋과 지역 배치(엑셀) → ④ 이름 있는 정예 + 정예 수식어 → ⑤ 1막 퀘스트·대사 → ⑥ 슬라이스와 다른 점 정리

**지역 연결 순서** — 한 줄로 이어지고 선택 던전은 옆길 (⛩ = 웨이포인트)

```
무너진 본산 → 백팔 계단 ⛩ → 안개 산길 ⛩ → 산 아래 마을 ⛩ (거점)
 → 다랑이 논
 → 서낭당 고개 ⛩
 → 버려진 화전민 마을 ⛩ ─ 옆길: 폐금광 1~2층
 → 대나무 숲
 → 고분 언덕 ⛩ ─ 옆길: 옛 왕릉 1~2층
 → 창귀 골짜기 ⛩
 → 산군의 굴
```

- **산군의 굴은 창귀 골짜기 끝**에 있음. 슬라이스의 "마을 뒷산에서 굴로 바로 가는 길"은 **슬라이스 전용**.
- **웨이포인트 7곳**: 마을(서낭당), 백팔 계단·안개 산길(입구 장승 — 슬라이스와 같음), 서낭당 고개, 화전민 마을, 고분 언덕, 창귀 골짜기. 두 지역마다 하나꼴, 선택 던전 입구 지역에는 꼭 하나.

**플레이 시간과 레벨** (엑셀 경험치 공식 기준 계산)

- 1막 전체 **약 1시간 30분**: 슬라이스 부분 15분 + 큰길 6지역 35분 + 던전 4층 20분 + 마을·퀘스트·이동 15분 + 보스 3분.

- **선택 던전까지 모두**: 지금 귀신 수로는 17 (두억시니·석인 경험치가 큼) → 던전 귀신 수를 줄이고 정예·보물 상자로 보상을 채워 **15 안팎**으로 맞춤 (③에서 숫자 확정).

### 1막 새 귀신 상세 (② — 2026-10-15 확정)

> 슬라이스 귀신(망자·창귀·도깨비불·산군 — 아래 "슬라이스 귀신 상세")에 더해 1막 나머지 귀신의 **움직임과 공격 방식**. 수치 원본은 엑셀 **"귀신" 시트** (새 행 7개 추가: `changgwi_howler`·`changgwi_leader`·`dokkaebibul_red`·`dokkaebibul_white`·`dokkaebibul_white_small`·`dueoksini_rock`·`son`). 공통 규칙(맞으면 반응, 큰 공격은 빨간 범위로 미리 표시)은 슬라이스와 같음. 거리·시간 값은 `EnemyData`에 둠.

| **굶어 죽은 망자** | 빠른 근접 | 바닥에 **쓰러져 있다가** 플레이어가 4m 안에 오면 0.8초 만에 일어나 달려듦 (시체 더미 기습). 일어난 뒤는 망자보다 빠르고 약함 |

| **울부짖는 창귀** | 호출 | 살아 있는 동안 **8초마다 울음** → 반경 15m 안의 잠든 귀신을 **계열과 상관없이** 모두 깨움 (보통 창귀는 무리당 한 번, 창귀만). 먼저 잡을 대상 |
| **창귀 무리장** | 무리 강화 | 크고 단단함. 8m 안 창귀 **이동·공격 속도 +20%**. 무리장이 죽으면 남은 창귀가 **3초 동안 겁먹고 흩어짐** |
| **붉은 불** | 자폭 | 도망치지 않고 다가옴 → 2m 안에서 **1초 예고 후 폭발** (반경 2.5m, 피해 ×2.5, 화). 예고 중에 잡으면 터지지 않음 |
| **흰 불** | 분열 | 도깨비불처럼 거리 유지·발사 (음 피해). 죽으면 **작은 흰 불 2개**로 나뉨 (체력 40%·피해 50%, 다시 나뉘지 않음) |
| **두억시니** | 탱커 (폐금광) | 평타 + **6초마다 내려찍기** (1초 예고, 반경 3m, 피해 ×2). 맞으면 **1.5초 동안 이동 속도 −50%** ("짓누르는 귀신", 기절 아님 — 사용자 결정) |
| **바위 두억시니** | 단단한 탱커 | 두억시니와 같은 패턴, **방어력만 높음** (방어 50, 조금 느림 — 사용자 결정) |
| **석인** | 느리고 단단함 (고분·왕릉) | **한 종류만** (사용자 결정). 잠든 동안 석상처럼 서 있다가 깨어날 때 돌가루가 떨어짐. 2.5초마다 내려치기. 체력 50% 아래에서 **한 번 "굳기"** — 3초 동안 받는 피해 −70% |
| **어둑시니** (정예) | 커짐 | **캐릭터가 바라보는 방향**(정면 약 60°) 안에 있으면 1초마다 크기·피해 +10% (최대 ×2), 벗어나면 천천히 줄어듦. 처음 크기 ×0.6. 숲 깊은 곳·던전 곁가지 끝. 먹 안개 본체와 같은 규칙 (`00` C) |
| **손** (떠돌이 정예) | 손 있는 날 전용 | 항상 정예. 무리 없이 천천히 떠돎, 지도 표시 없음 (`00` A) |

- **재활용**: 굶어 죽은 망자 = 잠듦 상태에 "누운 자세" 추가 / 역병 망자 독 장판 = 부적 폭발 범위 피해 + 지속 시간 / 울부짖는 창귀 = 창귀 호출 반복 / 붉은 불 = 산군 덮치기 예고 원 / 흰 불 = 죽을 때 귀신 생성 / 두억시니 느려짐 = 둔화 상태 이상 하나 (나중에 수 속성 둔화와 같이 씀).
- **모양** (임시): 슬라이스처럼 색·크기로 구분 — 굶어 죽은 망자 마른 회색, 역병 망자 초록빛, 울부짖는 창귀 붉은 주황, 무리장 1.4배, 붉은 불·흰 불은 색, 두억시니 1.6배 검붉은색, 바위 두억시니 회갈색, 석인 돌색 1.3배, 어둑시니 검은 그림자.

### 슬라이스 귀신 상세 (S2 — 2026-10-14 확정)

> 체력·피해·공격 간격·속도·저항 같은 **수치는 밸런스 엑셀 "귀신" 시트가 원본**입니다 (몬스터 레벨 1·일반 등급 기준). 여기는 **움직임과 공격 방식**을 정합니다. 거리·시간 값도 `EnemyData`나 귀신별 설정에 두어 코드 수정 없이 바꿀 수 있게 합니다.

**공통 규칙**

- 움직임 순서: **잠듦 → 발견 → 쫓아감 → 공격** (도깨비불만 "거리 유지·도망"이 더 있음). 잠듦·깨어남은 S1-11 3단계(고정 배치 무리)와 같은 구조를 씀.
- **맞으면 무조건 반응** (2026-10-14 플레이 테스트): 거리와 상관없이 **맞은 귀신은 바로 깨어나 쫓아옴** + **같은 무리 전체가 함께 깨어남** (먼 곳에서 원거리로 쳐도 가만히 맞고만 있지 않게). 한번 싸움이 붙은 귀신은 플레이어가 **추격 포기 거리**(엑셀 `EnemyLeashRange` 25m)보다 멀어질 때까지 계속 쫓아옴 — 인식 거리(10m) 밖이라고 멈추지 않음. 추격을 포기하면 **처음 선 자리로 돌아가면서 체력을 모두 회복**하고 다시 잠듦 (2026-10-15 사용자 결정, 초당 최대 체력 50% — 엑셀 `EnemyReturnHealPerSecond`·`BalanceConfig.enemyReturnHealPerSecond`, 도착하면 가득).
- **큰 공격은 반드시 미리 보여 줌**: 바닥에 빨간 범위를 0.5~1초 표시한 뒤 피해 (부적 폭발 조준 원 재활용). 피할 수 있어야 공정하게 느껴짐.
- 슬라이스에서는 임시 모양(Capsule·Cube)에 **색·크기로만** 구분.

**망자 (기본 근접)** — 지금의 적 그대로

- 수치: 엑셀 그대로 (체력 30, 피해 5, 1.5초마다 공격, 속도 3.5). 회색 재질, 사람 크기. 느리게 다가와 때리는 "기준 귀신".

**창귀 (빠른 떼거리)**

- 수치: 체력 18, 피해 4, 1초마다 공격, 속도 5.5 (플레이어보다 빠름). 마른 체형(가늘고 작은 Capsule), 흐린 주황빛.
- **부르는 소리**: 처음 플레이어를 발견한 창귀가 **0.5초 멈춰서 울고**, 반경 **12m** 안의 잠든 창귀가 모두 깨어나 몰려옴. **무리당 한 번만**. 우는 동안 먼저 잡으면 떼가 오지 않음 (실력으로 대처하는 지점).
- 근처에서 "살려 줘…" 자막 (S4 "망자의 목소리" 연출과 연결).

**도깨비불 (원거리)**

- 수치: 체력 20, 피해 6 (**화** 속성), 2초마다 발사, 속도 4, 수 저항 −25% (수 속성에 약함).
- 바닥에서 **1.5m** 떠 있음. 플레이어와 **6~9m** 거리를 유지하며 불덩이 발사.
- 불덩이 속도 **초속 8m** — 옆으로 걸으면 피할 수 있는 속도 (부적 투사체 코드 재활용).
- 플레이어가 **4m** 안으로 들어오면 반대쪽으로 **3m** 달아남. 달아난 뒤 **5초 동안은 다시 달아나지 않음** (계속 도망만 다니지 않게).
- 화상(지속 피해)은 슬라이스 이후 ("능력치 & 계산식" ⑤ — `03_아이템_능력치_경제.md`).

**산군 (1막 보스)**

- 몬스터 레벨: 슬라이스 **8** (지역 5 + 보스 +3) / 정식 게임 16.
- **기본 체력 700** (엑셀 1500에서 줄임): 레벨 6~7 플레이어 기준 처치 약 **1.5~2분**, 2페이즈 회복을 더해도 2분 남짓. (1500이면 3.5~4분 — 처음 만나는 보스로 길고 15~20분 슬라이스에서 비중이 너무 큼)
- **1페이즈**

| 패턴 | 예고 | 범위 | 피해 | 간격 |
| --- | --- | --- | --- | --- |
| 앞발 휘두르기 | 0.5초 (앞쪽 부채꼴 표시) | 앞쪽 부채꼴 3m | 기본 피해 ×1 | 평타 (엑셀 공격 간격 1.8초) |
| 덮치기 | 1초 (플레이어 위치에 원 표시) | 반경 3m — 뛰어들어 내려찍음 | 기본 피해 ×2 | 8초마다 |
| 창귀 소환 | 포효 | 창귀 4마리 | — | 20초마다, 한 번에 최대 6마리 |

- **2페이즈 (체력 50% 이하)**
  - 시작할 때 포효 + 창귀 바로 소환. 소환 간격 20초 → **15초**.
  - **소환된 창귀는 경험치·드랍 없음** (산군을 살려 두고 창귀만 잡아 레벨을 올리는 것 방지, 산군 처치 후 레벨 8 예상 유지).
  - **창귀 삼키기**: 살아 있는 창귀에게 다가가 삼킴 → 1마리당 **체력 5% 회복 + 피해 +10%** (최대 **3번** 쌓임). 창귀를 먼저 잡으면 삼키지 못함 → "창귀를 먼저 정리하라"는 공략.
- 보스 공통 규칙(방 입구 닫힘, 플레이어 사망 시 체력 회복, CC 짧게, 플레이어 CC 면역 2초)은 `개발현황.md` S2 백로그 그대로.

### 슬라이스 지역 생성 상세 (S3 — 2026-10-14 확정)

> 숫자 원본은 밸런스 엑셀: 타일 상수는 **"상수"** 시트(`TileSize`·`TileDoorWidth`·`SafeTilesFromEntrance`·`MaxPacksPerTile`), 지역별 생성 규칙은 **"지역"** 시트의 `MainPathTiles`·`BranchMin`·`BranchMax`·`PathStyle` 열, 귀신 무리는 **"지역배치"** 시트(새로 추가). 대상은 슬라이스의 무작위 지역 2개 — **백팔 계단**(폐사찰 타일셋), **안개 산길**(산길·숲 타일셋).

**① 타일 규격**

- 한 칸 = **20m × 20m 정사각형** (플레이어가 걸어서 약 4초). **바닥 높이는 모두 같음** — 계단·언덕 느낌은 칸 안의 장식으로만 (높이가 다르면 이어 붙일 때 어긋남).
- 출입구 = **네 변의 가운데, 폭 6m**. 쓰지 않는 출입구는 **벽 마개** 조각(바위·담장)으로 막음.
- 타일 종류: **직선 · 꺾임 · T자 · 막다른 곳** 4종 + **입구 · 출구** 조각. 타일셋(폐사찰, 산길·숲)마다 한 벌씩. 슬라이스는 Cube로 만든 임시 타일.
- 크기는 일단 이렇게 정하고, 직접 걸어 보며 넓거나 좁으면 조정.

**② 생성 방식 — 큰길 + 곁가지**

- 격자 위에 입구 → 출구로 이어지는 **큰길**을 먼저 깔고, 큰길 중간에서 **곁가지**(막다른 길)를 뻗음. 곁가지 끝 = 정예 무리 자리 (항아리·상자는 슬라이스에서 뺌 — S6).

| 지역 | 큰길 | 곁가지 | 길 모양 |
| --- | --- | --- | --- |
| 백팔 계단 (레벨 2, 3분) | 6칸 | 1~2개 | **곧은 길** — 산을 내려가는 길이라 한 방향(북 → 남)으로만 나아가고 꺾임 적게 |
| 안개 산길 (레벨 3, 4분) | 8칸 | 2~3개 | **꼬불꼬불** — 꺾임 많이 |

- 조립이 끝나면 칸들을 메시 합치기(`StaticBatchingUtility.Combine`) → NavMesh 굽기(`NavMeshSurface.BuildNavMesh`) → 입구 칸에 플레이어 시작 위치(`RegionEntry`), 출구 칸에 다음 지역 출구(`RegionExit`).
- 생성은 **여러 프레임에 나눠서** 할 수 있게 만듦 (다음 지역을 미리 불러오는 동안 게임이 끊기지 않게 — `07` S7 ⑩ "매끄러운 지역 이동"). NavMesh는 비동기 굽기.
- 길이 겹쳐서 조립에 실패하면 몇 번 다시 시도하고, 그래도 안 되면 미리 정해 둔 기본 배치로 만듦 (게임이 멈추지 않게).

**③ 고정 이벤트 자리** (대본의 정해진 장면은 무작위가 아니라 정해진 칸)

- 백팔 계단: **출구 바로 앞 칸** — 창귀 2~3마리 첫 등장 + "살려 줘…" 자막.
- 안개 산길: **곁가지 끝 한 곳** — 마을 사람의 쪽지(기록 조각) / **큰길 중간 한 곳** — 무영이 남긴 표시.

**④ 귀신 배치** (엑셀 "지역배치" 시트가 원본)

| 지역 | 무리 | 예상 처치 수 |
| --- | --- | --- |
| 백팔 계단 | 망자 무리 5개 (3~5마리) + 정예 망자 무리 1개 (곁가지 끝, 정예 1 + 일반 2~3) + 출구 앞 창귀 2~3 | 약 25 |
| 안개 산길 | 망자 무리 3개 (3~5) + 창귀 무리 2~3개 (4~5, 먼저 발견한 창귀가 울어서 부름) + 도깨비불 무리 2개 (불 2~3 + 망자 1~2 섞임) + 정예 창귀 무리 1개 (곁가지 끝, 정예 1 + 일반 3~4) | 약 35~40 |

- 무리는 **칸 하나에 최대 1개**. **입구 칸과 그다음 칸에는 귀신 없음** (들어오자마자 맞지 않게).
- 무리는 S1-11의 고정 배치 무리(`EnemyPack`)를 그대로 씀 — 생성기가 칸마다 무리를 만들어 놓을 뿐, 잠듦·깨어남·등급 처리는 같음.
- **이름 있는 정예**(지역마다 하나, 파밍 목표)는 **슬라이스 이후**로 미룸.

**⑤ 다시 들어갈 때의 지도**

- **슬라이스**: 지역에 **들어갈 때마다 새 지도**를 만들고 귀신도 다시 배치. 지역 = 씬 구조라 씬을 다시 불러오면 생성기가 다시 돌아서 가장 간단함.
- **슬라이스 이후 (디아블로 2 방식)**: 게임을 새로 시작(이어하기 포함)할 때 지역별 **시드**(무작위 번호)를 정해 두고, 그 게임 동안은 같은 지역에 다시 가도 **같은 지도** — 새 게임을 시작하면 새 지도. 구현이 간단하면 슬라이스에서 바로 해도 됨.
- 그래서 생성기는 처음부터 **시드를 받아서 지도를 만드는 구조**로 만듦 (같은 시드 = 같은 지도). 시드는 `RegionManager` 한 곳에서 정해 넘김 → 나중에 "들어갈 때마다 새 시드"를 "게임마다 시드 저장"으로 바꾸기만 하면 됨. 개발자 UI(F1)에 지금 지도의 시드를 보여 주면 버그를 다시 만들어 보기도 쉬움.

**2막 보스: 타락한 대사형** — 페이즈마다 주묵 갈래 하나씩

- 1페이즈 (검당): 빠른 돌진, 3연타 베기
- 2페이즈 (부적당): 부적 투사체 난사, 부적 폭발 장판
- 3페이즈 (신당 + 물귀신 빙의): 신장 소환, 대웅전에 물이 차오르며 바닥 장판이 점점 늘어남
- 처치 후: "문을 연 건… 스승님이다" → 무영이 무너지는 장면

**2막 이야기 장치**

- 동료 원혼 퀘스트 (무녀의 신당 지하): 신당 대원의 원혼이 "그날 밤, 스승님이 대사형에게 무언가를 부탁했다"는 조각을 줌 → 2막 반전 암시.
- 마을의 한 (멈춘 물레방아 마을): 홍수로 마을을 잃은 처녀귀신의 사연. 풀어주면 황포 나루에 상점이 늘어남.

**새로 필요한 시스템**: 붙잡기, 저주(디버프), 무리 이동, 금 도깨비 도주 AI, 물이 차오르는 보스 장판
