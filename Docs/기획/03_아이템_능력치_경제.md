### 아이템 시스템

**장비 칸 10칸** (디아블로 2 구성, 디아블로식 인형 모양 장비 창)


| 칸     | 예시         | 칸   | 예시               |
| ----- | ---------- | --- | ---------------- |
| 주무기   | 지팡이, 검, 신칼 | 보조  | 부적첩, 방울, 호신 거울   |
| 머리    | 갓, 두건, 투구  | 몸   | 도포, 가죽 갑옷, 사슬 갑옷 |
| 손     | 토시         | 허리  | 요대(허리띠)          |
| 발     | 짚신, 가죽신    | 목   | 노리개, 염주          |
| 반지 ×2 | 옥가락지, 은가락지 |     |                  |


- **직업 전용 무기**: 부적사 = 지팡이 + 부적첩, 퇴마검사 = 한손 검(+ 등패·단검) 또는 양손 쌍수도, 무당 = 신칼 + 방울·부채. 방어구·장신구는 공용.
- **양손 무기 규칙**: 양손 무기(쌍수도 등)를 끼면 **보조 칸을 쓸 수 없음**. 대신 무기 피해가 큼.

**아이템 구성 = 기본 아이템 + 무작위 옵션**

- 기본 아이템: 이름, 종류, 기본 능력치(무기 = 공격력 범위, 방어구 = 방어력), 요구 레벨, (무기) 직업. 같은 종류가 **하품 · 중품 · 상품** 3단계로 다시 나옴 (디아블로 2의 노멀·익셉셔널·엘리트 — 아래 "기본 아이템의 품")
- 무작위 옵션 개수: 노멀 0 / 매직 1~2 / 레어 3~5 / 유니크 = 고정 옵션 + 고유 효과
- 이름: 매직 = "예리한 복숭아나무 검" (접두어 + 기본 이름), 레어 = 두 단어 무작위 조합 ("원혼의 송곳", "달빛 도포")
- 툴팁 예시:

```
[레어] 원혼의 송곳
복숭아나무 검 · 주무기 · 검        ← 종류 줄 (항상 표시)
요구 레벨 15
공격력 12~18
─────────────
+15% 공격 속도
+8% 치명타 확률
+30 최대 체력
화(火) 저항 +12%
```

**숨겨진 아이템 레벨 (디아블로 2 방식, 플레이어에게 안 보임 — 툴팁엔 요구 레벨만)**

```
지역 레벨 → 몬스터 레벨 → 아이템 레벨 → 붙을 수 있는 옵션과 수치
```


| 대상      | 레벨           |
| ------- | ------------ |
| 일반 귀신   | 지역 레벨        |
| 정예 귀신   | 지역 레벨 +2     |
| 보스      | 지역 레벨 +3     |
| 떨어진 아이템 | 그 귀신의 몬스터 레벨 |


- 예) 1막 안개 산길 = 지역 레벨 3, 3막 혼이 쌓인 골짜기 = 지역 레벨 35 (아래 "지역 레벨 표" 참고)
- 각 옵션에는 "붙을 수 있는 최소 아이템 레벨"과 "레벨대별 수치 범위"가 있음 → 같은 레어 검이라도 뒤쪽 지역에서 주운 게 확실히 좋음.
- 귀문 균열은 단계가 오를수록 지역 레벨이 올라가는 같은 규칙.

**옵션 목록** (칸별로 붙을 수 있는 옵션과 수치는 아래 "능력치 & 계산식" 참고)


| 분류  | 옵션                                   |
| --- | ------------------------------------ |
| 공격  | 공격력, 공격 속도, 치명타 확률, 치명타 피해, 스킬 데미지 % |
| 생존  | 최대 체력, 방어력, 처치 시 체력 회복, 이동 속도        |
| 기력  | 최대 기력, 기력 회복, 기력 소모 감소               |
| 저항  | 화(火)·수(水)·독(毒)·음(陰) 저항               |
| 특수  | 스킬 랭크 +1, 아이템 발견 확률, 엽전 획득량          |


- **저항 4종은 귀신과 연결**: 화 = 도깨비불·화염 / 수 = 물귀신·황천강 / 독 = 역병 망자 / 음 = 처녀귀신의 저주·차사 → "2막 전에 수 저항 장비 챙기기" 같은 파밍 목적이 생김.

| 매직      | 쪽빛  | 옵션 1~2개                                                                       |

**물약·화폐 — 하나하나 줍는 번거로움 없애기**


| 항목         | 내용                                                                            |
| ---------- | ----------------------------------------------------------------------------- |
| 보혈환(補血丸)   | 체력 회복, **충전식 4회**, Q 키                                                        |
| 청심환(淸心丸)   | 기력 회복, **충전식 3회**, W 키 (지금의 기력 물약을 대체)                                        |
| 충전         | 거점 마을·서낭당(웨이포인트)에 닿으면 전부 충전 / 귀신이 가끔 떨어뜨리는 **기운 구슬**을 **걸어서 지나가면** 자동으로 1회 충전 |
| 물약 강화 (추후) | **약방(藥房) 주인** NPC에게 엽전을 내고 충전 횟수·회복량 증가 (3막 용병 "의원"과 다른 인물)                   |
| 귀환         | 소모품이 아닌 **무한 사용 기본 능력** (시전 3초, 맞으면 취소), B 키                                  |
| 엽전         | 화폐, **계정 공용** (모든 캐릭터가 함께 씀). **걸어서 지나가면 자동으로 주움**. 상점·스킬 초기화·용병 고용·물약 강화에 사용 |


- 가방에는 **장비만** 남음 → 지금의 "물약 묶음 ×N", "물약 줍기" 코드는 정리 대상.
- 상인 NPC = **보부상** (사고팔기), **대장장이** (추후: 옵션 하나 다시 굴리기 — 디아블로 4의 마법 부여)

**기존 아이템 정리**: 지금의 무기·방어구 8종은 **기본 아이템**으로 그대로 사용. 단 "벼락 맞은 대추나무 검"은 **유니크**로 올리고, 기본 아이템 자리에는 "대추나무 검"을 둠. (아이콘 파일 이름도 함께 변경)

**일부러 넣지 않는 것 (1인 개발 범위)**

- 내구도·수리 (귀찮음 대비 재미가 적음)
- 능력치 포인트 분배 (힘·민첩 등) — 스킬 포인트 + 장비로 충분 (디아블로 4 방식)
- 크기가 다른 인벤토리 칸 (디아블로 2의 테트리스) — **모든 아이템 1칸** 유지
- 아이템 감정 (식별 두루마리)

**이름 & 번역 규칙 (추후 영어·중국어·일본어 출시 대비)**

- 핵앤슬래시 플레이어는 이름보다 **아이콘·등급 색·종류 줄**로 아이템을 판단 → 직관성은 종류 표시가, 분위기는 고유 이름이 맡음.


| 층                     | 규칙                                              | 예시 (한국어 → 영어)                                                                                 |
| --------------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------- |
| ① 종류 (칸·분류)           | 어느 언어든 바로 아는 **보편 단어**만                         | 검, 지팡이, 투구, 갑옷, 장갑, 신발, 허리띠, 목걸이, 반지 → Sword, Staff, Helm...                                  |
| ② 기본 아이템              | **"재료·특징 + 보편 종류"**, 뜻으로 번역 가능해야 함              | 복숭아나무 검 → Peachwood Sword / 비단 도포 → Silk Robe / 사슬 갑옷 → Chainmail                             |
| ③ 고유명사 (유니크·세트·귀신·지역) | 한국 색채는 여기서. **뜻으로 번역**, 안 되는 것만 **로마자 + 짧은 설명** | 벼락 맞은 대추나무 검 → Lightning-Struck Jujube Blade / 도깨비 → Dokkaebi / 산군 → Sangun the Mountain Lord |


- 툴팁에는 항상 **종류 줄**(예: "몸 · 갑옷")을 이름 아래에 표시.
- 어려운 옛말(쇄자갑, 피갑 등)은 한국 플레이어에게도 낯서므로 기본 아이템 이름에 쓰지 않음.
- **기술 원칙**:
  - 아이템은 **이름이 아니라 ID**로 관리 (예: `weapon_peachwood_sword`). 아이콘·세이브·드랍 테이블 모두 ID 기준.
  - 화면 글자는 **Unity Localization 패키지**의 언어별 표(String Table)에서 가져옴. 지금은 한국어 표만 채우고, 나중에 다른 언어 표 추가.
  - 무작위 이름은 **언어별 조립 규칙** 사용 (한국어 "예리한 복숭아나무 검" / 영어 "Keen Peachwood Sword of the Fox").
  - **용어집**: 주묵·부적사·산군 등 핵심 용어의 영어 표기를 한 곳에 정리 (번역가에게 전달용).
  - 중국어·일본어 폰트: Noto Sans SC·JP를 NotoSansKR의 대체 폰트로 연결 (출시 직전에 해도 됨).

**데이터 구조 (Cursor 작업용 메모)**

- `ItemBase` (ScriptableObject): 기본 아이템 정보 (ID, 이름 키, 종류, 칸, 기본 능력치, 요구 레벨, 직업, 아이콘)
- `AffixData` (ScriptableObject): 옵션 종류, 최소 아이템 레벨, 레벨대별 수치 범위
- `ItemData` (저장용): 기본 아이템 ID, 등급, 아이템 레벨, 굴린 옵션 목록
- **세이브 형식 버전 3**: 옛 세이브의 아이템은 노멀 아이템으로 변환해서 불러옴
- `ItemType`, `ItemRarity` 등 enum은 세이브에 번호로 저장되므로 **새 값은 맨 뒤에 추가** (기존 규칙)

### 능력치 & 계산식

> 2026-10-13 초안. 수치는 출발점이고, 밸런스는 나중에 `BalanceConfig`·표의 숫자만 바꿔서 조정.

**원칙**

- **플레이어의 힘은 대부분 장비에서** (디아블로 4 방식). 레벨업은 체력·기력 조금 + 스킬 포인트. 능력치 포인트 분배 없음.
- **피해 유형 5가지**: 물리 + 속성 4종(**화·수·독·음**) — 저항 4종과 1:1.
- **곱셈 구간 분리**: 같은 종류의 % 증가는 **더하고**, 다른 구간끼리는 **곱함** → 한 옵션만 몰아 쌓으면 효율 감소, 다양한 옵션에 의미.
- **모든 상수는** `BalanceConfig` **하나에** 모아 코드 수정 없이 조정.

**플레이어 능력치**


| 분류  | 능력치                  | 기본값          | 상한                           |
| --- | -------------------- | ------------ | ---------------------------- |
| 공격  | 무기 피해 (최소~최대)        | 맨손 1~3       |                              |
|     | 추가 피해 %              | 0            |                              |
|     | 스킬 피해 %              | 0            |                              |
|     | 속성 피해 % (화·수·독·음 각각) | 0            |                              |
|     | 치명타 확률               | 5%           | 75%                          |
|     | 치명타 피해               | +50%         |                              |
|     | 공격 속도 (시전 속도)        | 0            | +100%                        |
| 방어  | 최대 체력                | 100 + 레벨당 10 |                              |
|     | 방어력 → 물리 피해 감소       | 0            | 85%                          |
|     | 저항 4종 → 속성 피해 감소     | 0%           | 75% (아이템 "최대 저항 +%"로 최대 80%) |
|     | 피해 감소 % (모든 피해)      | 0            | 50%                          |
|     | 체력 재생 (초당)           | 0            |                              |
|     | 처치 시 체력 회복           | 0            |                              |
| 기력  | 최대 기력                | 100 + 레벨당 2  |                              |
|     | 기력 회복 (초당)           | 5            |                              |
|     | 기력 소모 감소             | 0            | 40%                          |
| 유틸  | 이동 속도                | 0            | +50%                         |
|     | 쿨타임 감소               | 0            | 40%                          |
|     | 물약 회복량 %             | 0            |                              |
|     | 아이템 발견 %             | 0            | (효율 점감)                      |
|     | 엽전 획득 %              | 0            |                              |
|     | 스킬 랭크 +N             | 0            |                              |


- 지금 게임과 달라지는 점: "공격력" → **무기 피해** (레벨업으로 오르지 않음, 지금은 +5) / 치명타 10%·2배 → **기본 5%·×1.5** (장비로 올림) / "스킬 = 공격력 × 2" → **스킬마다 무기 피해 배율** (예: 부적 투사체 120%).

**① 플레이어가 주는 피해**

```
기본 피해 = 무기 피해(최소~최대 중 무작위) × 스킬 배율

최종 피해 = 기본 피해
          × (1 + 추가 피해% + 스킬 피해%)      ← 같은 구간은 더함
          × (1 + 해당 속성 피해%)                ← 속성 스킬일 때만
          × (치명타면 1 + 치명타 피해%)
          × (1 − 적의 해당 저항%)
          × 레벨 차 보정
```

- 스킬 배율: 스킬마다 정하고 랭크가 오를수록 커짐 (예: 부적 투사체 랭크 1 = 120%, 랭크당 +10%).
- 스킬의 피해 유형: 스킬마다 하나 (예: 부적 투사체 = 물리, 부적 폭발·불씨 부적 = 화). 상세는 스킬 설계 때.
- 레벨 차 보정: 적이 플레이어보다 높으면 **1레벨당 −3%** (최대 −45%) — 무리한 진행 방지.

**② 플레이어가 받는 피해**

```
물리 피해:  받는 피해 = 적 피해 × (1 − 물리 피해 감소) × (1 − 피해 감소%)
속성 피해:  받는 피해 = 적 피해 × (1 − 해당 저항%)     × (1 − 피해 감소%)

물리 피해 감소 = 방어력 ÷ (방어력 + 15 × 적 레벨 + 50)     (최대 85%)
```

- 방어력은 **적 레벨과 비교** → 1막의 좋은 갑옷도 3막에선 효과 감소 → 장비 교체 동기. 예) 방어력 200: 레벨 10 적 상대 50%, 레벨 36 적 상대 25%.
- 저항은 %가 그대로 감소율. 엔딩 후 난이도에서 저항 감점 (흉몽 −20%, 말세 −40% — "엔드게임 & 난이도") → 저항 파밍 목적.

**③ 적 능력치 (몬스터 레벨 기반)**

```
적 체력 = 귀신 종류별 기본 체력 × 체력 레벨 배율
적 피해 = 귀신 종류별 기본 피해 × 피해 레벨 배율
체력 레벨 배율 = 1.12 ^ (몬스터 레벨 − 1)     (레벨 13 ≈ 3.9배, 36 ≈ 53배, 55 ≈ 455배)
피해 레벨 배율 = 1.09 ^ (몬스터 레벨 − 1)     (레벨 13 ≈ 2.8배, 36 ≈ 20배, 55 ≈ 105배)  ← 2026-10-13 분리
```

- 실제 구현은 **레벨별 표**, 위 식은 표의 초깃값.
- 정예: 체력 ×3, 피해 ×1.5 / 이름 있는 정예: 체력 ×6, 피해 ×1.8 (하수인 ×1.5) / 보스: 따로 정함.
- 적도 방어력·저항을 가짐 (예: 물귀신 = 수 저항 높고 화 저항 낮음). **면역(100%)은 만들지 않음** (디아블로 2의 면역은 빌드 하나를 통째로 막는 문제).

**④ 그 밖의 계산**


| 항목             | 식                               |
| -------------- | ------------------------------- |
| 공격·시전 시간       | 기본 시간 ÷ (1 + 공격 속도%)            |
| 쿨타임            | 기본 쿨타임 × (1 − 쿨타임 감소%)          |
| 기력 소모          | 기본 소모 × (1 − 기력 소모 감소%)         |
| 아이템 발견 (실제 효과) | 아이템 발견% × 250 ÷ (아이템 발견% + 250) |

### 망자의 호패 & 혼백첩 — 대표 시스템 (2026-10-15 확정)

> 이 게임의 대표 시스템 ("차별점 원칙" ② — `00_기획_개요.md`). 주제: **귀신도 원래 사람이었다 → 호패(귀신의 혼)는 풀어 주고, 유니크(물건의 혼)는 태운다.** 3막 반전("부적은 혼을 태운 것")과 결말(혼을 희생할 것인가)을 플레이로 겪게 함. 수치는 초안 — 엑셀로 옮길 때 조정.

**흐름**

```
귀신 처치 → 가끔 호패가 떨어짐 → 줍는 순간 망자의 목소리 한 줄

```

**① 망자의 호패**
- 장비가 아닌 **따로 쌓이는 물건** (혼백첩 안에 보관, 인벤토리 칸을 차지하지 않음). 바닥 이름표는 먹색.
- 드랍: 일반 귀신 1% / 정예 5% / 이름 있는 정예 25% / 보스 첫 처치 100%, 이후 20%. 귀문 균열·세계 난이도에서도 같은 규칙 (난이도 배율은 나중에).
- 한 장 = **망자 이름**(무작위, 예: "창귀 · 박돌쇠의 호패") + **계열 효과** 1줄 + **재질**.
- 계열 효과 (1막 기준 5계열, 2·3막 계열은 그 막을 만들 때 추가). 치명타 계열(원래 어둑시니)은 어둑시니 삭제로 빠짐 → **2막 계열을 만들 때 치명타 효과를 맡을 계열을 다시 정함** (2026-10-15):

| 계열 | 성격 | 기본 효과 (잡목) | 같은 계열 3장 보너스 |
|---|---|---|---|
| 망자 | 체력 | 최대 체력 +3% | 체력 30% 아래에서 받는 피해 −15% |
| 창귀 | 속도 | 이동 속도 +3% | 처치 시 2초 동안 이동 속도 +20% |
| 도깨비불 | 원소 | 화(火) 피해 +3% | 원소 피해가 5% 확률로 작은 폭발 |
| 두억시니 | 방어 | 방어력 +3% | 축지(회피) 뒤 1초 동안 받는 피해 −30% |
| 석인 | 저항 | 모든 저항 +3% | 상태 이상 지속 시간 −25% |

- **재질 = 등급** (실제 조선 호패가 신분에 따라 재질이 달랐던 것):

| 재질 | 확률 | 효과 배율 |
|---|---|---|
| 잡목 | 50% | ×1 |
| 소목 | 28% | ×1.5 |
| 황양목 | 15% | ×2 |
| 녹각(사슴뿔) | 6% | ×3 |
| 상아 | 1% | ×4 + 특수 효과 1줄 (계열마다 1~2개, 예: 창귀 상아 — 축지 충전 +1) |

- **목소리**: 계열마다 처음 몇 번은 주울 때 붓글씨 자막 한 줄 (예: "어미 얼굴만 한 번 더 보고 싶었는데…"). 계열당 약 10줄, 망자 이름과 함께 기록됨.
- 같은 호패는 겹쳐 쌓음 (계열 + 재질이 같으면 같은 것으로 봄, 이름은 마지막 것을 표시).

**② 혼백첩(魂魄帖)** — 무영에게서 받는 책. 거점 또는 단축키로 엶 (키는 S 단계에서 정함). 부적사의 보조 무기 "부적첩"과 다른 것.
- **호패 쪽 (왼쪽)**: 호패 칸 처음 **2칸** → 막 보스(산군·대사형·스승)를 처음 잡을 때마다 +1 → 엔딩 후 +1 = **최대 6칸**. 거점에서는 언제든, 바깥에서는 서낭당(웨이포인트) 근처에서 바꿈.
- **혼 부적 쪽 (오른쪽)**: 유니크 아이템을 태워 고유 효과를 **혼 부적**으로 영구 등록 (아이템은 사라짐). 칸 3개 — **무기 혼 · 몸 혼 · 장신구 혼** (무기 유니크는 무기 혼에만, 방어구는 몸 혼에만, 반지·목걸이는 장신구 혼에만). 거점에서 바꾸기 무료.
  - 수치: 혼 부적은 **원래 아이템 고유 효과의 최솟값** (진짜 아이템을 낄 이유가 남게). 같은 유니크를 다시 태워도 수치는 그대로 (중복 등록 없음).
  - 등록 비용: **엽전** (아이템 가치 × 2 안팎, 엑셀에서 정함).
  - 세트 아이템은 못 태움. 동료의 유품(퀘스트 유니크)은 태울 수 있지만 **확인 창 + 무영 한마디**.
  - 태울 때 연출: 붉은 불꽃 + 짧은 비명 같은 소리. **3막 반전 뒤에는** 첫 등록 때 무영 대사 ("…우리도 혼을 태우고 있었던 거네.").
- **공덕 명부 (뒤쪽)**: 풀어 준 망자의 이름이 계열별로 남음. 백로그 "귀신 도감"과 합칠 수 있음 (도감을 만들 때 정함).

**③ 남는 호패 — 풀어 주기(천도)만 있음** (태우기·혼불 재료 없음, 2026-10-15 사용자 결정)
- 혼백첩에서 호패를 골라 **풀어 주기** → 호패는 사라지고 그 계열의 **공덕**이 쌓임.
- 공덕: 같은 계열 **10장 풀어 줄 때마다 그 계열 효과 +1%** (예: 망자 공덕 3단계 = 최대 체력 +3%), **계열당 최대 +10%**. 재질이 좋을수록 장수로 더 셈 (잡목 1 / 소목 2 / 황양목 3 / 녹각 5 / 상아 10).
- 연출: 호패가 흰 빛으로 흩어지며 목소리 한 줄 ("고맙소…").
- **엔딩 연결**: 풀어 준 총 수가 기준(예: 300장) 이상이면 엔딩의 무영 대사 한 줄이 바뀜 ("네가 보내 준 사람들, 저쪽에서 만났어."). 멀티 엔딩이 아니라 대사 한 줄.

**④ 언제 만드나**
- **슬라이스에는 넣지 않음** (확정된 범위 유지).
- 호패 + 혼백첩 호패 쪽 + 풀어 주기: **1막 확장 때** (1막 나머지 귀신과 함께).
- 혼 부적 쪽: **유니크가 늘어날 때** (유니크 고유 효과 작업과 함께).
- 미리 챙길 것: 유니크 **고유 효과를 아이템과 떼어 낸 데이터**로 만들기 → 📬 [전달-25].

**③ 이름 만들기**

- **매직** = 수식어 1개 + 기본 이름 (예: "단단한 무명 도포", "날랜 짚신"). 옵션마다 수식어 하나 (엑셀 "옵션" `MagicPrefix`: 최대 체력 = 튼튼한, 추가 피해 = 사나운, 무기 피해 = 예리한, 방어력 = 단단한, 화 저항 = 불막이, 모든 저항 = 액막이, 이동 속도 = 날랜 …). 옵션이 2개면 **수치가 더 높은 쪽**(그 옵션 범위 안에서 몇 % 위치인지로 비교) 수식어를 씀.
- **레어** = 앞말(공용 20개) + 뒷말(칸별 4~5개) 무작위 (예: "그믐 수의", "원혼의 뿌리", "핏빛 가락지").

  - 뒷말: 지팡이 = 장대·뿌리·가지·지팡이·회초리 / 부적첩 = 경전·비망록·서첩·주문·봉인 / 머리 = 갓·관·두건·머리 / 몸 = 도포·수의·껍질·장삼 / 손 = 손·토시·발톱·손아귀 / 허리 = 띠·고리·매듭·허리띠 / 발 = 걸음·발자국·신·짚신 / 목 = 염주·매듭·노리개·목걸이 / 반지 = 가락지·고리·눈·옥

- 이름 조립은 언어별 규칙 함수 하나에 모음 (지금은 한국어만).

```
다음 레벨 필요 경험치 = 500 × 레벨 ^ 1.5           (ExpBase 100 → 500)
처치 경험치 = 귀신 BaseExp × 몬스터 레벨 ^ 0.9
            × 정예 3배 (ExpEliteMult)
            × 슬라이스 1.5배 (SliceExpMult, 정식 게임 1)
            × 낮은 레벨 귀신 감소 (5레벨 이상 낮으면 0.2배 — 기존 규칙)
```

- 레벨업에 필요한 처치 수(망자 기준): 레벨 2 ≈ 15마리 → 13 ≈ 47 → 36 ≈ 86 → 49 ≈ 103. 레벨이 오를수록 천천히.
- 슬라이스 시뮬 (슬라이스 배율 1.5): 본산 끝 레벨 2 → 백팔 계단 끝 4 → 안개 산길 끝 5 → 마을 끝 **6** (시작 무료 랭크 2 + 스킬 포인트 5 — 제웅은 레벨 5에 해금(S5), 산군 기준 레벨 6~7과 맞음) → 산군 처치 후 8.
- 엔딩 뒤 고레벨(40~50) 곡선은 엔드게임 설계 때 다시 봄.

### 기본 아이템의 품(品) — 하품·중품·상품 (2026-10-15 확정)

> 디아블로 2의 노멀 · 익셉셔널 · 엘리트를 가져옴. 아이템 **등급**(노멀·매직·레어·유니크·세트 — 옵션이 몇 개 붙나)과는 다른 축이라 이름을 **품**으로 따로 둠 (몬스터 "유니크"를 "이름 있는 정예"로 바꾼 것과 같은 이유). 영어는 Normal · Exceptional · Elite.
> 숫자 원본은 밸런스 엑셀 **"기본아이템"** 시트 `Family`(종류 ID)·`Grade`(Low 하품 / Mid 중품 / High 상품) 열, 드랍 범위는 **"상수"** `BaseItemDropWindow`.

**① 구조**

- **기본 아이템 = 종류 × 품**. 칸마다 종류가 4개(몸은 도포·갑옷 두 줄이라 8개)이고, 같은 종류가 하품 → 중품 → 상품으로 **이름과 기본 능력치만 좋아져서** 다시 나옴 (예: 무명 두건 → 중품 두건 → 상품 두건).
- **품이 정하는 것**: 요구 레벨, 기본 능력치(무기 피해·방어력·부적첩 최대 기력).
- **아이템 레벨이 정하는 것**: 붙는 옵션과 수치 (지금 규칙 그대로 — "옵션" 시트 T1~T3). 하품 아이템도 높은 지역에서 주우면 옵션 수치는 높음 → 디아블로 2처럼 "옵션 좋은 하품"과 "기본이 튼튼한 상품"을 저울질.
- **장신구(목·반지)는 품이 없음** (기본 능력치가 없어서). 옵션만 아이템 레벨로 오름.
- **유니크는 정해진 기본 아이템 하나에 붙음** — 1막 유니크는 하품 바탕, 중품·상품 유니크는 그 품을 쓰는 막·엔드게임 때 따로 만듦 (디아블로 2와 같음). 하품 아이템·저레벨 유니크도 끝까지 쓸 수 있게 **품 올리기**(아래 ⑦)를 둠.

**② 품별 요구 레벨** (막 기준)

| --- | --- | --- |
| 하품 | 1 · 4 · 8 · 12 | 1막 (슬라이스는 1·4만) |
| 중품 | 16 · 20 · 24 · 28 | 2막 ~ 3막 앞 |
| 상품 | 34 · 38 · 42 · 46 | 3막 끝 · 엔딩 후 · 귀문 균열 |

- **드랍 범위**: 요구 레벨이 **아이템 레벨 이하**이고 **아이템 레벨 − 12 이상**인 종류만 떨어짐 (`BaseItemDropWindow` = 12). 예) 아이템 레벨 20 → 요구 8~20 종류만 (하품 무명 두건 같은 것은 안 나옴). 범위 안에서는 고르게.

**⑤ 화면 표시**

- **아이콘·바닥 모양은 종류마다 하나**를 세 품이 같이 씀 (디아블로 2처럼) — 중품·상품은 아이콘 테두리에 작은 문양(중품 한 줄 · 상품 두 줄)만 더함 → 그림 작업은 종류 수만큼.

**⑥ 종류별 고정 능력치** (2026-10-15 확정 — 값은 사용자가 나중에 다듬음)

- 기본 아이템마다 **고정 능력치 1줄** (디아블로의 "고유 옵션"). 같은 칸이라도 종류를 고를 이유가 생김 — 도포는 기력·스킬 쪽, 갑옷은 체력·방어 쪽.

- **고치는 곳은 엑셀 한 군데**: "기본아이템" 시트 `FixedStat`(옵션 Id — 칸을 누르면 **고르기 목록**이 뜸)·`FixedValue`(하품 값, 퍼센트는 0.05 = 5%). 문서의 표는 처음 값 기록용이고, 바꿀 때는 엑셀만 고치면 됨.
- 옵션 목록에 없는 능력치가 필요하면 "옵션" 시트에 줄을 더하고 **칸 열(MainHand~Ring)을 모두 비워 둠** → 무작위 옵션으로는 안 붙고 고정 능력치로만 씀 (예: `evade_recharge` 축지 충전 시간 감소).

**⑦ 옵션 단계** (2026-10-15 확정)

- 무작위 옵션의 수치 범위를 **단계 1~11**로 나눔. 단계가 오를수록 범위가 올라감.
- **떨어질 때의 단계 = 올림(아이템 레벨 ÷ 5)** (`OptionStepLevelSize`) — 아이템 레벨 1~5 = 1단계, 6~10 = 2단계 … 51~55 = 11단계. 슬라이스(아이템 레벨 1~8)는 1~2단계.
- 옵션마다 **굴림 위치**(그 단계 범위 안에서 몇 % 자리인지, 0~100%)를 기억함 → 단계가 바뀌어도 위치는 그대로, 수치만 새 단계 범위로 옮김. 매직 이름 고르기(옵션 2개면 위치가 높은 쪽)도 같은 값을 씀.
- 수치는 엑셀 **"옵션단계"** 시트(단계 1~11의 최소·최대, 자동 계산). 고치는 곳은 "옵션" 시트의 기준값 3개 — **T1 = 2단계, T2 = 5단계, T3 = 9단계** — 나머지 단계는 그 사이를 고르게 채움 (1단계 = T1의 75%, 10·11단계 = T3 위로 이어서).
- 툴팁: 옵션 줄 끝에 작은 글씨로 단계 (예: "최대 체력 +38 · 7단"). Alt를 누르면 그 단계의 범위도 보임 ("33~60").

**⑧ 품 올리기 (대장장이)** (2026-10-15 확정)

- 대장장이에게 **올릴 아이템 + 재료**를 맡김. 재료 = **같은 칸, 한 품 위의 기본 아이템** (등급 상관없음 — 하얀 노멀도 됨). 재료는 사라짐. 엽전 = 결과 아이템 가치 × 3 (`UpgradeCostMult`).
- 결과:
  1. 품 한 칸 위 (하품 → 중품 → 상품, **두 번까지**). 종류·등급·이름·옵션 줄은 그대로, 요구 레벨과 기본·고정 능력치는 새 품 값.
  2. 아이템 레벨 = **재료의 아이템 레벨** → 옵션 단계를 그 레벨로 다시 정함 (굴림 위치 그대로).
  3. **단계 보너스 +0 ~ +2** (확률 50% / 35% / 15% — `UpgradeStepBonus0~2`). 보너스는 모든 옵션에 똑같이 붙고, 두 번 올리면 쌓임 (최대 +4, 단 11단계를 넘지 않음). 툴팁에 "벼림 +2"처럼 표시.
- 그래서 잘 붙은 하품 레어 → 상품으로 올리면 갓 주운 같은 레벨 아이템보다 **좋을 수도** 있음 (보너스 운). 바닥의 하얀 중품·상품 = "재료"라는 쓸모.
- **유니크도 올릴 수 있음**: 고정 옵션은 엑셀 "유니크"의 범위를 드랍 레벨 단계 기준으로 보고, 같은 굴림 위치로 새 단계에 옮김 (옵션단계 시트의 두 단계 수치 비율만큼 커짐). 고유 효과는 그대로 (무기 피해 % 기준이라 저절로 커짐).
- **장신구**: 품이 없으니 재료 = 같은 칸 장신구 (아이템 레벨이 더 높은 것). 결과는 아이템 레벨·단계만 바뀜 + 단계 보너스, 두 번까지.
- **원혼 깃든 아이템은 봉인을 풀어야** 올릴 수 있음 (아래).
- 언제: 대장장이는 1막 마을 탈환 뒤 문을 엶. 중품 재료가 생기는 **2막 개발 때** 품 올리기를 만듦 (옵션 단계·굴림 위치 저장은 슬라이스 S6부터 — 세이브를 나중에 바꾸지 않게).

**데이터 (Cursor 작업용 메모)**: `ItemBase`에 `family`(종류 ID)·`grade`(품, enum `ItemGrade` = Low·Mid·High — 세이브에 번호로 저장되면 맨 뒤에 추가 규칙) 추가. 드랍할 기본 아이템을 고를 때 `BaseItemDropWindow` 범위로 거름. 세이브의 아이템은 기본 아이템 ID로 저장하므로 바뀌는 것 없음. 슬라이스 작업(S6) 때 열만 미리 만들어 두면 됨 (값은 모두 Low). `ItemData`의 옵션은 **옵션 Id + 굴림 위치(0~1) + 단계**로 저장(수치는 저장하지 않고 계산), 아이템에는 **벼림 횟수·단계 보너스**도 저장 — 처음부터 이 모양이면 품 올리기·원혼 봉인 때 세이브를 바꿀 필요 없음. 고정 능력치는 `ItemBase`의 `fixedStat`·`fixedValue` × 품 배율.

### 원혼 깃든 아이템 (2026-10-15 확정)

> 대박 순간 + 끼고 다니는 동안의 목표. 주제 "귀신도 원래 사람이었다"와 같은 줄기 — 물건에 깃든 원혼의 한을 풀어 줌. 숫자 원본은 엑셀 **"상수"** `SealedChance`·`SealedBonusStep`, 조건은 **"원혼조건"** 시트(새로).

- **나오는 것**: 레어·유니크가 떨어질 때 **2%** 확률로 원혼이 깃듦 (1막부터, 슬라이스에는 없음). 바닥 이름표가 **흐릿한 회색 붓글씨로 흔들리고** 낮은 울음소리 (멀리서도 "떴다"를 앎).
- **봉인된 동안 옵션이 모두 가려짐** (사용자 결정 — 나머지 옵션을 보고 버리지 않게): 툴팁에는 등급 색·기본 아이템·고정 능력치와 "봉인된 옵션 N줄 (???)"만. 옵션은 작동하지 않고 기본·고정 능력치만 작동. 유니크면 이름도 "??? (원혼 깃든 유니크)".
- **봉인 풀기**: 끼고 다니며 조건을 채움 — 예: "망자 계열 300마리 정화", "이름 있는 정예 3마리 정화" (조건은 깃들 때 무작위 1개, 지금 지역의 귀신 계열이 나오기 쉬움). 툴팁·장비 창에 진행 막대 (120 / 300). 봉인된 아이템을 여러 개 껴도 모두 함께 셈.
- **풀리면**: 망자의 목소리 한 줄(그 물건의 원래 주인) → 옵션이 한꺼번에 드러남 + **무작위 옵션 1줄의 단계 +2** (`SealedBonusStep` — 유니크는 고정 옵션 1줄) + 그 계열의 **호패 1장** (재질은 소목 이상). 이름 앞에 "한 풀린"이 붙음 (예: "한 풀린 그믐 수의").
- 봉인된 채로는 **품 올리기·혼백첩 태우기 불가**, 팔기·버리기는 됨 (확인 창). 대장장이 다시 굴리기도 불가.
- 데이터: `ItemData`에 봉인 여부·조건 Id·진행 수 (세이브 맨 뒤에 추가). 처치 이벤트를 듣는 작은 계수기 하나 (퀘스트 "귀신 처치" 목표와 같은 이벤트).
- 언제: **1막 확장 때** (호패와 함께 — 계열·목소리·호패를 같이 씀).
