### 아이템 시스템

**장비 칸 10칸** (디아블로 2 구성, 디아블로식 인형 모양 장비 창)


| 칸     | 예시         | 칸   | 예시               |
| ----- | ---------- | --- | ---------------- |
| 주무기   | 지팡이, 검, 신칼 | 보조  | 부적첩, 방울, 호신 거울   |
| 머리    | 갓, 두건, 투구  | 몸   | 도포, 가죽 갑옷, 사슬 갑옷 |
| 손     | 토시         | 허리  | 요대(허리띠)          |
| 발     | 짚신, 가죽신    | 목   | 노리개, 염주          |
| 반지 ×2 | 옥가락지, 은가락지 |     |                  |


- **직업 전용 무기**: 부적사 = 지팡이 + 부적첩, 퇴마검사 = 한손 검(+ 등패·단검) 또는 양손 쌍수도, 무당 = 신칼 + 방울·부채. 방어구·장신구는 공용.
- **양손 무기 규칙**: 양손 무기(쌍수도 등)를 끼면 **보조 칸을 쓸 수 없음**. 대신 무기 피해가 큼.

**아이템 구성 = 기본 아이템 + 무작위 옵션**

- 기본 아이템: 이름, 종류, 기본 능력치(무기 = 공격력 범위, 방어구 = 방어력), 요구 레벨, (무기) 직업
- 무작위 옵션 개수: 노멀 0 / 매직 1~2 / 레어 3~5 / 유니크 = 고정 옵션 + 고유 효과
- 이름: 매직 = "예리한 복숭아나무 검" (접두어 + 기본 이름), 레어 = 두 단어 무작위 조합 ("원혼의 송곳", "달빛 도포")
- 툴팁 예시:

```
[레어] 원혼의 송곳
복숭아나무 검 · 주무기 · 검        ← 종류 줄 (항상 표시)
요구 레벨 15
공격력 12~18
─────────────
+15% 공격 속도
+8% 치명타 확률
+30 최대 체력
화(火) 저항 +12%
```

**숨겨진 아이템 레벨 (디아블로 2 방식, 플레이어에게 안 보임 — 툴팁엔 요구 레벨만)**

```
지역 레벨 → 몬스터 레벨 → 아이템 레벨 → 붙을 수 있는 옵션과 수치
```


| 대상      | 레벨           |
| ------- | ------------ |
| 일반 귀신   | 지역 레벨        |
| 정예 귀신   | 지역 레벨 +2     |
| 보스      | 지역 레벨 +3     |
| 떨어진 아이템 | 그 귀신의 몬스터 레벨 |


- 예) 1막 안개 산길 = 지역 레벨 3, 3막 혼이 쌓인 골짜기 = 지역 레벨 35 (아래 "지역 레벨 표" 참고)
- 각 옵션에는 "붙을 수 있는 최소 아이템 레벨"과 "레벨대별 수치 범위"가 있음 → 같은 레어 검이라도 뒤쪽 지역에서 주운 게 확실히 좋음.
- 귀문 균열은 단계가 오를수록 지역 레벨이 올라가는 같은 규칙.

**옵션 목록** (칸별로 붙을 수 있는 옵션과 수치는 아래 "능력치 & 계산식" 참고)


| 분류  | 옵션                                   |
| --- | ------------------------------------ |
| 공격  | 공격력, 공격 속도, 치명타 확률, 치명타 피해, 스킬 데미지 % |
| 생존  | 최대 체력, 방어력, 처치 시 체력 회복, 이동 속도        |
| 기력  | 최대 기력, 기력 회복, 기력 소모 감소               |
| 저항  | 화(火)·수(水)·독(毒)·음(陰) 저항               |
| 특수  | 스킬 랭크 +1, 아이템 발견 확률, 엽전 획득량          |


- **저항 4종은 귀신과 연결**: 화 = 도깨비불·화염 / 수 = 물귀신·황천강 / 독 = 역병 망자 / 음 = 처녀귀신의 저주·차사 → "2막 전에 수 저항 장비 챙기기" 같은 파밍 목적이 생김.

**등급 5종**


| 등급      | 색   | 내용                                                                            |
| ------- | --- | ----------------------------------------------------------------------------- |
| 노멀      | 흰색  | 기본 능력치만 (등급 확률은 "드랍 & 경제")                                                    |
| 매직      | 파랑  | 옵션 1~2개                                                                       |
| 레어      | 노랑  | 옵션 3~5개, 무작위 이름                                                               |
| 유니크     | 주황  | 고정 이름·옵션 + 고유 효과. 예) "벼락 맞은 대추나무 검: 공격 시 10% 확률로 낙뢰". 서브 퀘스트 "동료의 유품"도 여기에 속함 |
| 세트 (신규) | 초록  | 같은 세트를 여러 개 끼면 추가 효과. 예) "주묵 수장의 유품" 4종                                       |


**물약·화폐 — 하나하나 줍는 번거로움 없애기**


| 항목         | 내용                                                                            |
| ---------- | ----------------------------------------------------------------------------- |
| 보혈환(補血丸)   | 체력 회복, **충전식 4회**, Q 키                                                        |
| 청심환(淸心丸)   | 기력 회복, **충전식 3회**, W 키 (지금의 기력 물약을 대체)                                        |
| 충전         | 거점 마을·서낭당(웨이포인트)에 닿으면 전부 충전 / 귀신이 가끔 떨어뜨리는 **기운 구슬**을 **걸어서 지나가면** 자동으로 1회 충전 |
| 물약 강화 (추후) | **약방(藥房) 주인** NPC에게 엽전을 내고 충전 횟수·회복량 증가 (3막 용병 "의원"과 다른 인물)                   |
| 귀환         | 소모품이 아닌 **무한 사용 기본 능력** (시전 3초, 맞으면 취소), B 키                                  |
| 엽전         | 화폐, **계정 공용** (모든 캐릭터가 함께 씀). **걸어서 지나가면 자동으로 주움**. 상점·스킬 초기화·용병 고용·물약 강화에 사용 |


- 가방에는 **장비만** 남음 → 지금의 "물약 묶음 ×N", "물약 줍기" 코드는 정리 대상.
- 상인 NPC = **보부상** (사고팔기), **대장장이** (추후: 옵션 하나 다시 굴리기 — 디아블로 4의 마법 부여)

**기존 아이템 정리**: 지금의 무기·방어구 8종은 **기본 아이템**으로 그대로 사용. 단 "벼락 맞은 대추나무 검"은 **유니크**로 올리고, 기본 아이템 자리에는 "대추나무 검"을 둠. (아이콘 파일 이름도 함께 변경)

**일부러 넣지 않는 것 (1인 개발 범위)**

- 내구도·수리 (귀찮음 대비 재미가 적음)
- 능력치 포인트 분배 (힘·민첩 등) — 스킬 포인트 + 장비로 충분 (디아블로 4 방식)
- 크기가 다른 인벤토리 칸 (디아블로 2의 테트리스) — **모든 아이템 1칸** 유지
- 아이템 감정 (식별 두루마리)

**이름 & 번역 규칙 (추후 영어·중국어·일본어 출시 대비)**

- 핵앤슬래시 플레이어는 이름보다 **아이콘·등급 색·종류 줄**로 아이템을 판단 → 직관성은 종류 표시가, 분위기는 고유 이름이 맡음.


| 층                     | 규칙                                              | 예시 (한국어 → 영어)                                                                                 |
| --------------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------- |
| ① 종류 (칸·분류)           | 어느 언어든 바로 아는 **보편 단어**만                         | 검, 지팡이, 투구, 갑옷, 장갑, 신발, 허리띠, 목걸이, 반지 → Sword, Staff, Helm...                                  |
| ② 기본 아이템              | **"재료·특징 + 보편 종류"**, 뜻으로 번역 가능해야 함              | 복숭아나무 검 → Peachwood Sword / 비단 도포 → Silk Robe / 사슬 갑옷 → Chainmail                             |
| ③ 고유명사 (유니크·세트·귀신·지역) | 한국 색채는 여기서. **뜻으로 번역**, 안 되는 것만 **로마자 + 짧은 설명** | 벼락 맞은 대추나무 검 → Lightning-Struck Jujube Blade / 도깨비 → Dokkaebi / 산군 → Sangun the Mountain Lord |


- 툴팁에는 항상 **종류 줄**(예: "몸 · 갑옷")을 이름 아래에 표시.
- 어려운 옛말(쇄자갑, 피갑 등)은 한국 플레이어에게도 낯서므로 기본 아이템 이름에 쓰지 않음.
- **기술 원칙**:
  - 아이템은 **이름이 아니라 ID**로 관리 (예: `weapon_peachwood_sword`). 아이콘·세이브·드랍 테이블 모두 ID 기준.
  - 화면 글자는 **Unity Localization 패키지**의 언어별 표(String Table)에서 가져옴. 지금은 한국어 표만 채우고, 나중에 다른 언어 표 추가.
  - 무작위 이름은 **언어별 조립 규칙** 사용 (한국어 "예리한 복숭아나무 검" / 영어 "Keen Peachwood Sword of the Fox").
  - **용어집**: 주묵·부적사·산군 등 핵심 용어의 영어 표기를 한 곳에 정리 (번역가에게 전달용).
  - 중국어·일본어 폰트: Noto Sans SC·JP를 NotoSansKR의 대체 폰트로 연결 (출시 직전에 해도 됨).

**데이터 구조 (Cursor 작업용 메모)**

- `ItemBase` (ScriptableObject): 기본 아이템 정보 (ID, 이름 키, 종류, 칸, 기본 능력치, 요구 레벨, 직업, 아이콘)
- `AffixData` (ScriptableObject): 옵션 종류, 최소 아이템 레벨, 레벨대별 수치 범위
- `ItemData` (저장용): 기본 아이템 ID, 등급, 아이템 레벨, 굴린 옵션 목록
- **세이브 형식 버전 3**: 옛 세이브의 아이템은 노멀 아이템으로 변환해서 불러옴
- `ItemType`, `ItemRarity` 등 enum은 세이브에 번호로 저장되므로 **새 값은 맨 뒤에 추가** (기존 규칙)

### 능력치 & 계산식

> 2026-10-13 초안. 수치는 출발점이고, 밸런스는 나중에 `BalanceConfig`·표의 숫자만 바꿔서 조정.

**원칙**

- **플레이어의 힘은 대부분 장비에서** (디아블로 4 방식). 레벨업은 체력·기력 조금 + 스킬 포인트. 능력치 포인트 분배 없음.
- **피해 유형 5가지**: 물리 + 속성 4종(**화·수·독·음**) — 저항 4종과 1:1.
- **곱셈 구간 분리**: 같은 종류의 % 증가는 **더하고**, 다른 구간끼리는 **곱함** → 한 옵션만 몰아 쌓으면 효율 감소, 다양한 옵션에 의미.
- **모든 상수는** `BalanceConfig` **하나에** 모아 코드 수정 없이 조정.

**플레이어 능력치**


| 분류  | 능력치                  | 기본값          | 상한                           |
| --- | -------------------- | ------------ | ---------------------------- |
| 공격  | 무기 피해 (최소~최대)        | 맨손 1~3       |                              |
|     | 추가 피해 %              | 0            |                              |
|     | 스킬 피해 %              | 0            |                              |
|     | 속성 피해 % (화·수·독·음 각각) | 0            |                              |
|     | 치명타 확률               | 5%           | 75%                          |
|     | 치명타 피해               | +50%         |                              |
|     | 공격 속도 (시전 속도)        | 0            | +100%                        |
| 방어  | 최대 체력                | 100 + 레벨당 10 |                              |
|     | 방어력 → 물리 피해 감소       | 0            | 85%                          |
|     | 저항 4종 → 속성 피해 감소     | 0%           | 75% (아이템 "최대 저항 +%"로 최대 80%) |
|     | 피해 감소 % (모든 피해)      | 0            | 50%                          |
|     | 체력 재생 (초당)           | 0            |                              |
|     | 처치 시 체력 회복           | 0            |                              |
| 기력  | 최대 기력                | 100 + 레벨당 2  |                              |
|     | 기력 회복 (초당)           | 5            |                              |
|     | 기력 소모 감소             | 0            | 40%                          |
| 유틸  | 이동 속도                | 0            | +50%                         |
|     | 쿨타임 감소               | 0            | 40%                          |
|     | 물약 회복량 %             | 0            |                              |
|     | 아이템 발견 %             | 0            | (효율 점감)                      |
|     | 엽전 획득 %              | 0            |                              |
|     | 스킬 랭크 +N             | 0            |                              |


- 지금 게임과 달라지는 점: "공격력" → **무기 피해** (레벨업으로 오르지 않음, 지금은 +5) / 치명타 10%·2배 → **기본 5%·×1.5** (장비로 올림) / "스킬 = 공격력 × 2" → **스킬마다 무기 피해 배율** (예: 부적 투사체 120%).

**① 플레이어가 주는 피해**

```
기본 피해 = 무기 피해(최소~최대 중 무작위) × 스킬 배율

최종 피해 = 기본 피해
          × (1 + 추가 피해% + 스킬 피해%)      ← 같은 구간은 더함
          × (1 + 해당 속성 피해%)                ← 속성 스킬일 때만
          × (치명타면 1 + 치명타 피해%)
          × (1 − 적의 해당 저항%)
          × 레벨 차 보정
```

- 스킬 배율: 스킬마다 정하고 랭크가 오를수록 커짐 (예: 부적 투사체 랭크 1 = 120%, 랭크당 +10%).
- 스킬의 피해 유형: 스킬마다 하나 (예: 부적 투사체 = 물리, 부적 폭발·불씨 부적 = 화). 상세는 스킬 설계 때.
- 레벨 차 보정: 적이 플레이어보다 높으면 **1레벨당 −3%** (최대 −45%) — 무리한 진행 방지.

**② 플레이어가 받는 피해**

```
물리 피해:  받는 피해 = 적 피해 × (1 − 물리 피해 감소) × (1 − 피해 감소%)
속성 피해:  받는 피해 = 적 피해 × (1 − 해당 저항%)     × (1 − 피해 감소%)

물리 피해 감소 = 방어력 ÷ (방어력 + 15 × 적 레벨 + 50)     (최대 85%)
```

- 방어력은 **적 레벨과 비교** → 1막의 좋은 갑옷도 3막에선 효과 감소 → 장비 교체 동기. 예) 방어력 200: 레벨 10 적 상대 50%, 레벨 36 적 상대 25%.
- 저항은 %가 그대로 감소율. 엔딩 후 난이도에서 저항 감점 (흉몽 −20%, 말세 −40% — "엔드게임 & 난이도") → 저항 파밍 목적.

**③ 적 능력치 (몬스터 레벨 기반)**

```
적 체력 = 귀신 종류별 기본 체력 × 체력 레벨 배율
적 피해 = 귀신 종류별 기본 피해 × 피해 레벨 배율
체력 레벨 배율 = 1.12 ^ (몬스터 레벨 − 1)     (레벨 13 ≈ 3.9배, 36 ≈ 53배, 55 ≈ 455배)
피해 레벨 배율 = 1.09 ^ (몬스터 레벨 − 1)     (레벨 13 ≈ 2.8배, 36 ≈ 20배, 55 ≈ 105배)  ← 2026-10-13 분리
```

- 실제 구현은 **레벨별 표**, 위 식은 표의 초깃값.
- 정예: 체력 ×3, 피해 ×1.5 / 보스: 따로 정함.
- 적도 방어력·저항을 가짐 (예: 물귀신 = 수 저항 높고 화 저항 낮음). **면역(100%)은 만들지 않음** (디아블로 2의 면역은 빌드 하나를 통째로 막는 문제).

**④ 그 밖의 계산**


| 항목             | 식                               |
| -------------- | ------------------------------- |
| 공격·시전 시간       | 기본 시간 ÷ (1 + 공격 속도%)            |
| 쿨타임            | 기본 쿨타임 × (1 − 쿨타임 감소%)          |
| 기력 소모          | 기본 소모 × (1 − 기력 소모 감소%)         |
| 아이템 발견 (실제 효과) | 아이템 발견% × 250 ÷ (아이템 발견% + 250) |


**⑤ 속성 상태 이상 (슬라이스 이후)** — 플레이어·귀신 모두 적용, 저항이 높으면 지속 시간도 감소


| 속성   | 상태 이상 | 효과                | 쓰는 귀신       |
| ---- | ----- | ----------------- | ----------- |
| 화(火) | 화상    | 지속 피해             | 도깨비불, 붉은 불  |
| 수(水) | 한기    | 이동·공격 속도 감소       | 물귀신, 황천 물귀신 |
| 독(毒) | 중독    | 지속 피해 + 체력 회복량 감소 | 역병 망자       |
| 음(陰) | 저주    | 받는 피해 증가          | 처녀귀신, 차사    |


**⑥ 칸별 아이템 옵션** — 칸마다 붙을 수 있는 옵션을 제한해 칸의 개성과 파밍 목표를 만듦

**⑦ 정예 귀신 수식어 (슬라이스 이후)**: 정예에게 무작위 수식어 1~3개 (디아블로 2 방식) — 예) 빠름, 화염 강화, 저주 오라, 분열(죽으면 작은 귀신으로 갈라짐), 흡혈, 단단함.

**구현 구조 (Cursor 작업용 메모)**

- `StatType` (enum): 능력치 종류. 세이브에 번호로 저장 → **새 값은 맨 뒤에 추가**.
- `StatModifier`: 값 + 종류(고정 더하기 / % 더하기 / % 곱하기) + 출처(장비, 레벨, 버프)
- `CharacterStats`: 기본값 + 레벨 + 장비 + 버프를 모아 최종값 계산. **장비·버프가 바뀔 때만 다시 계산** (매 프레임 계산 금지).
- `DamageCalculator`: ①② 식을 한 곳에. 플레이어와 귀신이 같은 함수 사용.
- `BalanceConfig` (ScriptableObject): 상한, 상수(15, 50, 1.12 등), 레벨별 표 → 에디터에서 숫자만 변경.

**직업 맞춤 드랍 (스마트 루팅)**: 무기가 떨어질 때 **70%는 지금 직업이 쓸 수 있는 무기** (디아블로 4 방식). 나머지 30%는 다른 직업용 → 창고에 모아 다른 캐릭터에게 주는 재미.

**유니크·세트 목록 (출시 목표 규모)**


| 종류     | 목표                      | 드랍 규칙                              |
| ------ | ----------------------- | ---------------------------------- |
| 유니크    | 약 36개 (막마다 직업별 3~4개 수준) | 아이템마다 **드랍 레벨** — 그 레벨 이상 지역에서만 나옴 |
| 세트     | 5세트 (세트당 2~4개)          | 같은 규칙                              |
