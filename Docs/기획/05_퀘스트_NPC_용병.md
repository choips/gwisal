**구조**

- 퀘스트 = **단계 목록**, 단계마다 목표 하나. 목표 종류를 정해 두면 새 퀘스트는 **데이터만 추가**.


| 목표 종류        | 예                       |
| ------------ | ----------------------- |
| 지역 도착        | "창귀 골짜기로 가기"            |
| 귀신 처치 (종류·수) | "장례 행렬 귀신 처치"           |
| 보스 처치        | "산군 처치"                 |
| 퀘스트 아이템 얻기   | "대원의 유품 찾기"             |
| NPC와 대화      | "무영과 대화"                |
| 원혼과 대화       | 망자의 목소리를 듣는 능력으로 원혼과 대화 |
| 물체 상호작용      | "서낭당 정화", "꽃 피우기"       |


- 상태: 잠김 → 받을 수 있음 → 진행 중 → 완료.
- **NPC 머리 위 표시**: "!" = 받을 수 있음, "?" = 완료 보고 (붓글씨 느낌).
- **추적기**: 화면 오른쪽 위에 현재 목표. **퀘스트 창(J 키)**: 막별 목록, 진행 상황, 동료 조각 수집 현황 (예: 3/6).
- **세이브**: 퀘스트 진행은 **캐릭터별**, 엔딩 여부만 **계정 공용**.
- **스토리 스킵 캐릭터**: 메인 퀘스트가 완료 상태로 시작 (웨이포인트·균열·용병 해금). **서브 퀘스트는 그대로 할 수 있음** (유품·스킬 포인트·물약 충전 획득 가능).
- 데이터 (Cursor 작업용 메모): `QuestData` (ScriptableObject: ID, 종류, 막, 시작 조건, 단계 목록, 보상, 대사 키) / `QuestManager` (귀신 처치·지역 도착·대화 같은 **게임 이벤트를 듣고** 단계를 진행 — 퀘스트마다 코드를 짜지 않음) / 퀘스트 글은 모두 **String Table**에서.

**자동 지도** (지역이 무작위 생성되므로 꼭 필요)

- 디아블로 2 방식: **탐험한 곳만** 그려짐. 미니맵(화면 구석) + 전체 지도(Tab).
- 퀘스트 목표, 웨이포인트, 출구, 거점 NPC 표시.
- **수묵 스타일** (먹 선으로 그린 지도).

### 용병

> 2026-10-13 확정. 싱글플레이에서 "혼자가 아닌 느낌" + 직업의 약점 보완. 1인 개발로 감당할 수 있게 단순하게.

**장비 3칸 — 플레이어 아이템을 그대로 사용**: **머리, 몸, 목** 3칸에 플레이어가 줍는 투구·갑옷·노리개를 끼움. **무기는 용병마다 고정**이고 레벨에 맞춰 자동으로 강해짐 → 활·화승총 같은 용병 전용 아이템을 새로 만들 필요 없음 (아이템 종류·드랍 테이블 그대로), 대신 "좋은 갑옷 하나 더 → 용병에게" 파밍 쓰임새.

**용병 3종** — 이름은 조선의 실제 군대 편제 **삼수병(三手兵)**(훈련도감의 사수·포수·살수)에서 가져오고, 치료사를 더함


| 용병         | 해금                       | 역할     | 배경                                                        | 성향 A                                   | 성향 B                                   |
| ---------- | ------------------------ | ------ | --------------------------------------------------------- | -------------------------------------- | -------------------------------------- |
| 착호갑사(捉虎甲士) | 1막 — **산군 처치 후** 산 아래 마을 | 원거리 딜러 | 조선에 실제로 있던 호랑이 사냥 부대. 산군을 잡으러 왔다가 부대를 잃고, 산군이 쓰러지자 마을에 남음 | **사수(射手)**: 활, 빠른 연사, 맞은 적 둔화          | **포수(砲手)**: 화승총, 느리지만 강한 한 방, 일직선 관통   |
| 떠돌이 검객     | 2막 — 황포 나루               | 근접 탱커  | 강을 따라 떠도는 무사. 오래전 대사형과 겨룬 적이 있어 2막 보스전 전후로 짧은 대사          | **등패수**: 칼 + 등패, 귀신의 공격을 끌어들임(도발), 단단함 | **살수(殺手)**: 쌍검, 빠른 연타, 주변 적 베기         |
| 의원         | 3막 — 일주문 야영지             | 회복·보조  | 생존자 진지의 치료사                                               | **침술사**: 주기적으로 플레이어 체력 회복, 위급할 때 큰 회복  | **약초꾼**: 탕약을 던져 공격력·이동 속도 증가 버프, 적에게 독 |


직업별 추천 조합: 부적사(원거리) ↔ 떠돌이 검객(등패수, 앞에서 막아 줌) / 퇴마검사(근접) ↔ 착호갑사·의원(침술사) / 무당(소환) ↔ 의원(약초꾼, 버프가 소환물에도 적용되면 시너지)

**능력치 (능력치 시스템 재사용)**

```
용병 체력     = 용병 종류별 기본 체력 × 레벨 성장 + 장비 체력
용병 무기 피해 = 용병 종류별 기본 무기 피해 × 레벨 성장
용병 방어·저항 = 장비에서 (플레이어와 같은 계산식)
```

- 목표 비중: 용병 피해는 **플레이어의 20~30%** (주인공을 대신하지 않고 보조). 귀신의 공격이 용병에게도 분산되어 플레이어의 압박 감소.

**조작·UI**

- **AI 자동 행동**: 따라다니며 알아서 싸우고 스킬 사용. **스킬 6칸을 차지하지 않음**.
- **용병 창**: 장비 3칸, 능력치, 성향, 해고·교체.
- **짧은 대사(바크)**: 플레이어와 같은 바크 시스템. 예) 착호갑사 "호랑이 냄새가 나는군", 의원 "무리하지 마시오".

**개발 관점**

- **아군 AI 공용화**: 용병·무당 소환물·부적사의 제웅·종이 학이 모두 "아군 AI"(따라다니기, 목표 고르기) 사용 → **한 번 만들어 같이 씀**.
- **개발 순서**: 1막 완성 후 **착호갑사 먼저** (아군 AI를 여기서 만들어 두면 무당이 쉬워짐) → 추천 순서 **용병(착호갑사) → 퇴마검사 → 무당**.
- ⚠️ 성능: 아군 개체 수 상한에 **용병 1명도 포함** (예: 소환물 6 + 용병 1 = 최대 7).
- 밸런스 엑셀 **용병 시트**: 종류·성향별 기본 체력, 무기 피해, 공격 간격, 고용 비용.
