### 🎨 아트 방향: 수묵 채색 (2026-10-12 확정)

- **참고 자료**: `Docs/ArtReference/` (귀살 목업 + 오카미 스크린샷 2장, 설명은 같은 폴더의 `README.md`). 대표 참고 게임: **오카미(大神)**.
- **핵심**: 한국 수묵화에 옅은 색을 입힌 스타일. 화면 대부분은 **먹(검정·회색)과 한지색**, 색은 **중요한 것에만** (붉은색 = 부적·피해·체력, 푸른색 = 기력·도깨비불, 노란색 = 부적·아이템).
- **기법**
  - 굵기가 변하는 **먹 외곽선** (외곽선 셰이더 하나로 서로 다른 에셋 팩의 모델도 통일감)
  - 화면 전체에 **한지 질감**을 얇게 덮음
  - 복잡한 텍스처 대신 **평평한 색 + 수채 그라데이션**
  - 먼 배경은 **먹 번짐 산 + 안개** 그림
  - 이펙트는 사실적 파티클 대신 **구름·소용돌이 문양**, 폭발은 **붉은 먹이 튄 원**
  - 그림자는 **먹물 덩어리**(블롭 섀도)
  - 귀신은 **불투명 + 테두리 빛**, 빛나는 것은 **가짜 빛**(바닥 그림)
  - UI는 **종이 카드 + 붓 획**, 충전식 물약은 **먹 단지·구슬 모양 충전 표시**, 장식으로 **낙관(붉은 도장)**
- **한국풍으로 (일본풍처럼 보이지 않게)**: 오카미는 일본 미술 기반이므로 같은 기법에 한국 소재를 씀 — 한옥 처마·기와·**단청**·일주문·홍살문, **민화·오방색**, 한국 **구름무늬(운문)**, **탈(하회탈 등)**·장승. 토리이·일본식 지붕·일본 요괴 디자인은 피함.
- **톤**: 오카미보다 **차분하고 어두운** 톤 (안개, 밤, 저승). 1막은 비교적 밝은 산수화, 2막은 푸른 물빛, 3막은 잿빛·먹빛으로 점점 어두워짐.
- **최적화와의 관계**: 이 스타일은 단순한 텍스처·적은 조명·가짜 빛·블롭 섀도 위주라 **저사양·모바일에 유리**함.
- **에셋 구매 시**: "에셋 구매 기준"(삼각형 수·텍스처 크기·URP 기본 셰이더)과 함께, **로우폴리·스타일라이즈드** 모델을 우선. 사실적 텍스처가 강한 팩은 피함 (외곽선 셰이더로 통일하기 어려움).

### 그래픽 & 성능 최적화 원칙

**최적화 5대 원칙**

1. **추측하지 말고 측정**: Unity **Profiler**(어디서 시간이 드는지), **Frame Debugger**(화면을 몇 번에 나눠 그리는지)로 확인한 뒤 고침.
2. **목표를 숫자로**: **최소 사양 기기**를 정하고, 그 기기에서 "낮음" 설정으로 **30fps** 유지가 기준. 한 프레임 예산 = 60fps 16.6ms / 30fps 33ms.
3. **병목 구분**


| 병목                                                                                                    | 원인                                   | 귀살에서 생길 곳            |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------ | -------------------- |
| CPU                                                                                                   | 스크립트, 귀신 AI·길찾기, 물리, 그리기 명령 수(드로우 콜) | 귀신 떼, 무작위 생성 맵의 조각 수 |
| GPU                                                                                                   | 화면 해상도, 반투명 겹침(오버드로), 그림자, 후처리, 조명   | 안개, 부적 이펙트, 반투명 귀신   |
| 메모리                                                                                                   | 텍스처, 소리                              | 에셋 팩, 지역 전환          |

4. **사양 차이는 품질 설정으로 흡수**: 무거운 요소는 처음부터 품질 설정으로 끌 수 있게 만듦.
5. **아트 방향이 최대의 최적화**: 사실적 그래픽보다 **스타일라이즈드(그림 같은) 그래픽**이 가볍고 오래감. → **수묵 채색으로 확정** (아래 "🎨 아트 방향" 참고)


**귀살 전용 규칙**

- **귀신을 반투명 셰이더로 만들지 않기**: 반투명 귀신이 겹치면 GPU가 같은 화면을 수십 번 다시 칠함 → **불투명 + 림 라이트(테두리 빛) + 발광 + 디더링**으로 귀신 느낌 표현.
- **이펙트에 진짜 조명(Light) 달지 않기**: 도깨비불·부적·혼불은 **발광 재질 + 바닥에 빛 모양 그림**으로 가짜 빛 표현.
- **무작위 생성 맵**: 실행 중에 조립되므로 조명 굽기(Bake)가 어려움 → **해 하나 + 환경광(Ambient)** 위주의 조명 설계. 조각을 이어 붙인 뒤 **메시 합치기**(`StaticBatchingUtility.Combine`)로 드로우 콜 감소.
- **귀신 AI**: 길찾기 목적지 갱신을 매 프레임이 아니라 **0.2~0.3초마다**, 귀신마다 시점을 엇갈리게. 멀리 있는 귀신은 잠재움 (고정 배치의 "다가오면 깨어남").
- **UI**: 귀신마다 World Space Canvas를 두지 않고, 체력바·데미지 숫자를 **화면 UI 하나에서 몰아 그림** (오브젝트 풀링과 함께).
- **지역 전환**: **비동기 로딩**(`LoadSceneAsync`) + 로딩 화면.
- 재질 복사본(`.material`)을 만들면 오브젝트를 지울 때 **재질도 함께 지움** (메모리 누수 방지).

**품질 설정 (안)**


| 항목                           | 낮음     | 중간       | 높음       |
| ---------------------------- | ------ | -------- | -------- |
| 렌더 스케일 (내부 해상도, GPU 효과 가장 큼) | 0.7    | 0.85     | 1.0      |
| 그림자                          | 끔 / 블롭 | 플레이어·보스만 | 전체, 고해상도 |
| 후처리 (블룸 등)                   | 끔      | 블룸만      | 전체       |
| 이펙트 밀도                       | 50%    | 75%      | 100%     |
| 프레임 제한                       | 30     | 60       | 60 / 무제한 |


- 처음 실행할 때 **기기 사양(**`SystemInfo`**)을 보고 추천 설정 자동 선택**. 설정 화면은 조작키 변경 화면과 같은 곳.

### 모바일 이식 대비 원칙

> 지금 모바일 버전을 같이 만드는 게 아니라, **나중에 구조를 뜯어고치지 않도록 방향만 잡아 두는 것**. 기준: "지금 하면 싸고, 나중에 하면 비싼 것"만 지금 챙긴다.
> 이미 유리한 점: URP 사용, 프로젝트에 Mobile / PC 품질 설정이 나뉘어 있음, 지역 단위 구조·짧은 귀문 균열(모바일의 짧은 플레이 시간), 충전식 물약·자동 줍기·6칸 스킬(디아블로 이모탈과 비슷한 조작량).

**🔴 지금 꼭 챙길 것**

1. **입력은 "행동 단위"로 설계**: Input Actions를 "이동 방향", "이 위치로 이동", "스킬 3번 사용"처럼 행동으로 정의 → 나중에 가상 조이스틱·스킬 버튼(터치)을 같은 행동에 연결만 하면 됨. 스킬은 **자동 조준**(가장 가까운 적)을 기본 지원. 부적 폭발의 "누르고 조준 → 떼서 발동"은 모바일에서 "버튼 드래그 조준"으로 옮김.
2. **마우스 올리기(hover)에만 기대는 기능 금지**: 모든 정보는 **탭(클릭)·길게 누르기로도** 볼 수 있어야 함. 지금의 아이템 툴팁(`ItemTooltipTrigger`)이 hover 전용 → S6 툴팁 개편 때 수정.
3. **오브젝트 풀링**: 부적·데미지 숫자·이펙트·적을 매번 `Instantiate`/`Destroy`하지 않고 미리 만들어 재사용 (지금 스크립트 13개가 매번 생성·삭제) → 모바일 끊김(GC 스파이크) 방지. 귀신 떼 설계라 특히 중요.
4. **에셋 구매 기준** (다시 사는 일이 없도록 처음부터 적용)


| 항목       | 기준                                              |
| -------- | ----------------------------------------------- |
| 플레이어 캐릭터 | 삼각형 5천~8천 개 이하                                  |
| 일반 귀신    | 삼각형 1천5백~3천 개 이하                                |
| 텍스처      | 대부분 1024 이하, 큰 것도 2048까지                        |
| 셰이더      | URP 기본(Lit / Simple Lit)으로 동작. 독자 셰이더가 많은 팩은 피함 |
| 표기       | "Mobile friendly" 또는 "Low poly" 우선              |


- 쿼터뷰 고정 카메라라 디테일이 크게 보이지 않으므로 이 기준으로도 충분.

5. **`Resources` 폴더 대신 직접 연결**: 아이템 아이콘을 `Resources.Load`로 불러오는 방식 → S1 아이템 구조 개편 때 `ItemBase`에 아이콘을 직접 연결. 콘텐츠가 커지면 **Addressables**(필요한 것만 불러오기)로 이동 — DLC 배포에도 같은 기술 사용.

**🟡 개발하면서 지킬 습관**

- 지역마다 **귀신 최대 동시 등장 수**를 데이터(지역별 배치 표)로 관리 → 모바일에서는 이 숫자만 줄임
- 실시간 조명은 **해 하나**, 나머지는 굽기(Bake)나 가짜 조명
- 그림자는 **플레이어·보스만**, 일반 귀신은 바닥 그림자 그림(블롭 섀도)
- 안개·반투명 이펙트를 **화면 가득 겹치지 않기** (안개 산길, 저승길 연출 주의)
- 후처리(블룸 등)는 **품질 설정으로 끌 수 있게**
- 매 프레임 쓰레기 만들지 않기 (`Update`에서 문자열 합치기, `new`, `Find` 금지)
- 앱이 백그라운드로 가면 **자동 저장** (`OnApplicationPause`) — 모바일은 앱이 언제든 강제 종료됨
- 가끔 **Mobile 품질 설정으로 바꿔서 플레이**해 보기

**🟢 이식할 때 해도 되는 것 (지금은 신경 쓰지 않음)**

- 가상 조이스틱, 모바일 전용 UI 배치, 노치(안전 영역) 대응, 버튼·글자 크기
- 텍스처 압축 형식(ASTC), 빌드 용량 최적화, 스토어 분할 다운로드

### 출시 전략

- **얼리 액세스 없이 정식 출시** (메인 스토리 3막 + 초기 직업 3종). 이후 DLC로 막·직업 추가.
- 개발자는 **직장과 병행**(주말·평일 저녁) → **출시 날짜를 정하지 않고**, 버티컬 슬라이스 → 막 단위로 완성해 나감.
- 플랫폼: **PC(Steam) 우선**. 게임패드·Steam Deck 지원. 모바일은 추후 이식 (원칙은 "모바일 이식 대비 원칙").
- 가격: 유료 판매 (DLC 별도 판매).
- **홍보는 개발 후반에 시작**: Steam 스토어 페이지 공개(위시리스트 모으기, 출시 약 1년 전 권장) → 데모로 Steam 넥스트 페스트·국내 인디 행사(BIC 등) 참가 → 개발 일지(짧은 영상) 공개. 버티컬 슬라이스를 다듬으면 데모로 쓸 수 있게 만들어 둠.

### 슬라이스 마무리 상세 (S7 — 2026-10-14 확정)

> 숫자 원본은 밸런스 엑셀 **"상수"** 시트(`AutoQualityLowVramMB`·`AutoQualityMidVramMB`·`SfxMaxSameSound`·`CharacterNameMaxLength`·`CharacterSlots`)와 **"경제"** 시트(`DeathGoldLossRatio`·`DeathGoldLossCapPerLevel`). 화면 글자는 모두 **String Table**.

**① 화면 흐름**

- **타이틀**: [이어하기] [캐릭터 선택] [설정] [종료]. 이어하기 = 마지막 캐릭터(`Account.json`의 마지막 칸)로 바로 시작, 캐릭터가 없으면 회색. 배경은 임시 수묵 그림 1장(본산 + 월식) + 붓글씨 제목 "귀살".
- **캐릭터 선택**: **8칸** — 칸마다 이름·직업·레벨·지금 지역. [새 캐릭터] [삭제] [시작]. 삭제는 **캐릭터 이름을 직접 입력**해야 지워짐.
- **캐릭터 만들기**: 직업 카드 3장 — 부적사만 선택 가능, 퇴마검사·무당은 "준비 중"(어둡게). 이름 **1~12자**(한글·영문·숫자), 다른 캐릭터와 겹치면 안 됨. "스토리 건너뛰기"는 슬라이스에서 숨김.

**② ESC 메뉴 & 저장 (디아블로 방식)**

- [계속하기] [설정] [저장하고 타이틀로] [저장하고 종료]. ESC 메뉴가 열린 동안 **게임 멈춤**.
- 직접 저장·불러오기 버튼은 없음 — 저장은 **자동 저장**(S1-12: 지역 이동 때) + 메뉴의 "저장하고 …", 불러오기는 타이틀의 이어하기·캐릭터 선택.
- 개발 중에 쓰던 빠른 저장·불러오기(S/L)는 **개발자 UI(F1)**로 옮겨서 남김.
- **ESC로 창 닫기 — 마지막에 연 창부터 하나씩** (2026-10-14 플레이 테스트): ESC를 누를 때마다 아래 순서로 **한 가지만** 함.
  1. 부적 폭발 **조준 중**이면 조준 취소 (지금 동작 그대로).
  2. 확인 창·고정된 툴팁 같은 **작은 팝업**이 있으면 그것을 닫음.
  3. 열린 창이 있으면 **가장 마지막에 연 창 하나**를 닫음 — 인벤토리(I)·개발자 UI(F1)·스킬 창(T)·상점·서낭당 이동 창·지도 겹쳐 보기(Tab)·기록 조각 창 등 모든 창.
  4. 아무 창도 없으면 **ESC 메뉴**를 엶 (S7 전까지는 아무것도 안 함). ESC 메뉴가 열려 있으면 ESC = [계속하기].
- 각 창의 단축키(I·F1·T·Tab)는 지금처럼 **켜기/끄기 그대로** — 맨 위 창이 아니어도 그 키로 바로 닫힘. 이미 열린 창을 단축키로 다시 앞으로 가져오지는 않음 (닫힘).
- 대화창·두루마리 컷신 중에는 ESC가 **아무것도 하지 않음** (실수로 이야기를 건너뛰지 않게 — 건너뛰기는 [건너뛰기] 버튼만).

**③ 사망 처리**

- 화면이 먹빛으로 번짐 → 대사 "…부적이… 찢어져…" → "잃은 엽전 N" → [깨어나기].
- 엽전 **5%** 잃음 (상한 = 레벨 × 100). 부활하면 **체력·기력·물약 가득**.
- 부활 위치: 마을 탈환 전 = **지금 지역의 입구** / 탈환 후 = **마을 서낭당** / 산군의 굴 = **굴 입구 앞** (산군 체력도 가득 — 보스 공통 규칙).
- 무작위 지역에서 죽으면 **같은 시드로 다시 불러옴** → 지도는 같고 귀신은 처음부터 다시 배치 (S3의 시드 구조 그대로 사용, 잡은 귀신을 기억하는 코드 필요 없음).
- **수작업 지역**(무너진 본산, 탈환 전 마을)에서 죽으면 **잡은 귀신은 죽은 채로** 남음 (퀘스트 "남은 귀신 N"도 그대로). 깨어 있던 귀신은 체력이 가득 차서 제자리로 돌아가 다시 잠듦. (고정 배치라 무리마다 "잡았음"만 기억하면 됨 — 지역을 떠나면 잊음)

**④ 슬라이스 클리어 화면**

- 무영의 마지막 대사 뒤 먹 번짐 → **"1막 데모를 클리어했습니다"**.
- 기록: 플레이 시간 · 처치 수 · 사망 횟수 · 최종 레벨 · 찾은 레어/유니크 수.
- 문구: "주묵의 이야기는 정식 게임에서 이어집니다".
- 버튼: **[마을로 돌아가기]** (계속 파밍, 산군 다시 잡기 가능 — 산군의 가죽 확정은 첫 처치만) **[타이틀로]**. 나중에 Steam 페이지가 생기면 위시리스트 버튼 추가.

**⑤ 설정 메뉴 (슬라이스: 그래픽·사운드만 채움)**

- **그래픽**: 품질 낮음/중간/높음(위 "품질 설정" 표), 해상도, 창 모드/전체 화면, 수직 동기화.
- **사운드**: 전체 · 음악 · 효과음 볼륨.
- **첫 실행 자동 추천**: 그래픽 메모리 **2GB 미만 또는 내장 그래픽 → 낮음**, **4GB 미만 → 중간**, 그 외 → 높음 (최소 사양 Iris Xe·UHD급 → 낮음).
- **게임플레이**: 아이템 이름 글자 크기·이름 박스 크기 슬라이더 (80~150% — `03` S6 ⑤-2, 2026-10-14 플레이 테스트).
- 조작·접근성·언어 탭은 자리만 두고 "준비 중".
- 설정은 **계정 공용** (`Account.json`).

**⑩ 매끄러운 지역 이동 — 미리 불러오기 (2026-10-14 확정, 게임 중 로딩 화면 없애기)**

> 원칙: **게임 중에는 로딩 화면을 보지 않게** 함. 다음 지역을 지금 지역을 도는 동안 뒤에서 다 만들어 두고, 출구에 닿으면 짧게 깜박이고 바로 들어감. 지역 = 씬 구조(S1-10)는 그대로.

- **언제 불러오나**: 지역에 들어가고 **2초 뒤**(도착 직후 끊김을 피하려고) 다음 지역을 뒤에서 불러오기 시작.
  - 씬은 `LoadSceneAsync`(추가 불러오기)로 불러오고, 무작위 지역이면 **시드를 미리 정해** 생성기를 바로 돌림.
  - 지도 조립·메시 합치기·NavMesh 굽기는 **여러 프레임에 나눠서** 함 (한 프레임에 조금씩, NavMesh는 비동기 굽기 `NavMeshSurface.UpdateNavMesh`). 미리 불러오는 동안 전투가 끊기면 안 됨.
  - 미리 만든 지역은 **잠든 상태**: 화면에 안 보이고, 귀신 AI·퀘스트("지역 도착")·지도·음악·장승은 **실제로 들어간 순간부터** 움직임.
- **출구에 닿으면**: 0.3초 어두워짐 → 플레이어를 새 지역 입구로 옮기고 새 지역을 깨움 → 0.3초 밝아짐 (모두 **약 0.6초**). 이전 지역은 그 뒤 천천히 내림. 밝아진 뒤 화면 위쪽에 **붓글씨 지역 이름 2초** (화면을 막지 않음) — **지역이 바뀔 때마다 매번** (출구·귀환·서낭당·장승·이어하기·다른 지역에서 부활 모두, 처음 가는 곳만이 아님).
- **어느 지역을 미리**: 앞으로 가는 쪽 하나만 (본산 → 백팔 계단 → 안개 산길 → 마을). 마을에서는 산군 퀘스트가 시작되면 **산군의 굴**을 미리. 거꾸로 이전 지역으로 돌아가는 길은 미리 하지 않음 (드묾 — 아래 "준비가 덜 됐을 때"처럼 처리).
- **미리 할 수 없는 이동은 원래 있는 시간으로 가림**:

| 이동 | 불러오는 동안 보이는 것 |
| --- | --- |
| 귀환 (B) | 시전 **3초** 동안 마을을 불러옴 (맞아서 취소되면 버림) |
| 서낭당·장승 | 이동 창에서 고르면 바로 불러오기 시작 + 순간이동 연출 약 1초 (부적이 타오르는 빛) |
| 사망 | 사망 화면(먹빛 → 대사 → 잃은 엽전 → [깨어나기]) 동안 다시 불러옴 |
| 타이틀 → 게임 (이어하기·새 캐릭터) | 여기만 로딩 화면 허용 (먹빛 + 붓글씨 지역 이름). 새 캐릭터는 두루마리 컷신 동안 본산을 불러옴 |

- **준비가 덜 됐을 때** (아주 빨리 출구에 닿은 경우 등): 어두운 화면에 붓글씨 지역 이름을 띄우고 준비될 때까지 기다림, 그동안 귀신은 멈춤. 예외 상황용 — 평소에는 보이지 않아야 함.
- **메모리·성능**: 지역 두 개가 잠깐 함께 올라감 — 슬라이스 지역은 작아서 괜찮음. ⭐ 최소 사양 흉내에서 **미리 불러오는 동안에도 30fps 유지** 확인 (안 되면 한 프레임에 하는 양을 줄임).
- 지역을 완전히 이어 붙여 걸어서 넘어가는 방식(디아블로 4)은 하지 않음 (지도·퀘스트·저장을 많이 고쳐야 함).

**⑩-2 카메라 (2026-10-14 플레이 테스트)**

- **마우스 휠 줌 없앰** — 카메라 거리·각도는 **고정** (디아블로 2처럼 모든 사람이 같은 시야로 플레이, 휠 입력 `Zoom` 행동도 정리).
- 보이는 범위는 **디아블로 2와 비슷하게**: 플레이어가 화면 가운데, 위아래로 약 **12~15m**, 좌우로 약 **15m**씩 보임 → 부적 투사체 사거리(15m)가 화면 가장자리쯤. 귀신·아이템이 작아 보이지 않을 정도.
- 정확한 거리·각도는 사용자가 직접 보며 정함: 개발자 UI(F1)에 **카메라 거리·각도 임시 슬라이더** → 마음에 드는 값을 정하면 그 값으로 고정하고 슬라이더는 뺌.

**⑪ 조작 범위 (2026-10-14 점검 때 추가)**
