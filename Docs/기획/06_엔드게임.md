### 엔드게임 & 난이도

> 2026-10-13 확정. 엔딩 후 반복 플레이의 흐름. 밸런스 엑셀 "난이도"·"균열" 시트에서 조정.

```
엔딩 → 흉몽 난이도 해금
   → 귀문 균열 / 방(榜) 의뢰 / 보스 반복 사냥  ← 장비·유니크·세트 파밍
   → 시련 균열로 단계 올리기 (10단계 달성)
   → 말세 난이도 해금 → 최고 단계 도전
   → (다른 직업을 스토리 스킵으로 시작 / 하드코어 도전)
```

**세계 난이도 3단계** (디아블로 4의 세계 등급 방식 — 스토리를 다시 하게 하는 대신 같은 세계를 더 위험하게 → 이미 만든 지역·보스 재사용, 콘텐츠 비용 거의 없음)


| 난이도    | 해금         | 귀신                                      | 저항 감점 | 보상                    |
| ------ | ---------- | --------------------------------------- | ----- | --------------------- |
| 평시(平時) | 처음부터       | 지역 레벨 그대로                               | 없음    | 기본                    |
| 흉몽(凶夢) | 엔딩         | 지역 레벨이 **플레이어 레벨 +2로 올라감** (낮은 지역도 위협적) | −20%  | 매직 이상 ×1.5, 경험치 ×1.5  |
| 말세(末世) | 시련 균열 10단계 | 흉몽 + 정예 수식어 +1개                         | −40%  | 유니크·세트 확률 ×2, 엽전 ×1.5 |


- 난이도는 **거점에서 언제든 변경**. 저항 감점 → 저항 장비 파밍의 목적.

**귀문 균열**


| 종류    | 규칙                                     | 목적            |
| ----- | -------------------------------------- | ------------- |
| 일반 균열 | 단계 선택, **시간 제한 없음**                    | 편하게 파밍        |
| 시련 균열 | **10분 제한**, 성공하면 **다음 단계 해금** + 보너스 상자 | 단계 올리기, 실력 증명 |


- 진행: ① 거점 **균열석**에서 종류·단계 선택 → ② 무작위 지역 1~2층 (해금한 막의 타일셋) → ③ 귀신 처치로 **원한 게이지** 충전 → ④ 가득 차면 **균열 주인**(보스급, 디아블로 3의 균열 수호자) 등장 → ⑤ 처치하면 보상 후 거점으로.
- **균열 변형** (단계 6 이상, 무작위 1~2개): 귀신이 빠름 / 죽은 귀신이 독 장판을 남김 / 금 도깨비 자주 출현 / 어둠(시야가 좁음) / 원한 게이지 2배 등.
- 단계 n의 지역 레벨 = 12 + 2n (단계 20 = 52). 막 클리어로 단계 상한이 열리고, 시련 균열 성공으로 그 안에서 한 단계씩 올라감.
- **최고 기록**: 직업별 시련 균열 최고 단계·최단 시간 (내 기록만), Steam 업적과 연결.

**방(榜) 현상 의뢰**: 거점 벽에 의뢰 **3~5개** (예: "옛 왕릉의 이름 있는 정예 처치", "대사형 3번 처치", "시련 균열 5단계 성공", "금 도깨비 2마리 처치"). 완료하면 **엽전 + 의뢰 상자**(등급이 보장된 장비), 하나 완료할 때마다 새 의뢰 (실제 시간과 무관). 스토리 지역을 엔드게임에서도 다시 쓰게 하는 장치.

**보스 반복 사냥**: 산군·대사형·불가살이·스승을 흉몽·말세에서 다시 잡을 수 있음. 보스마다 **전용 유니크** (예: 산군의 가죽) → 특정 아이템을 노리는 목표.

**하드코어 모드**: 캐릭터 생성 때 선택, **죽으면 그 캐릭터는 끝**. 죽은 하드코어 캐릭터는 **"망자 명부"**에 이름·직업·레벨·죽은 곳이 남음. 창고·엽전은 일반 캐릭터와 공유 (싱글플레이라 경제 걱정 없음). 하드코어 전용 Steam 업적.

**도력(道力)** (선택, 출시 후 업데이트로 미뤄도 됨): 레벨 50 이후 경험치로 "도력" 단계가 오르고, 단계마다 작은 능력치(체력 +1%, 피해 +1% 등) 선택 (디아블로 3의 정복자 레벨 방식, 최대 100단계).

**엔드게임 반복 주기 (목표)** — 30분 안팎의 짧은 플레이로도 성장이 느껴지게 (직장과 병행하는 플레이어, 모바일 이식에도 맞음)


| 활동      | 1회 시간  | 얻는 것          |
| ------- | ------ | ------------- |
| 일반 균열   | 5~8분   | 장비, 엽전        |
| 시련 균열   | 최대 10분 | 단계 상승, 보너스 상자 |
| 방 의뢰 1개 | 3~10분  | 보장 상자, 엽전     |
| 보스 사냥   | 2~3분   | 전용 유니크        |
