## 1. 모든 에셋에 공통인 느낌

**한 줄 요약**: 한국 수묵화에 옅은 색을 입힌 느낌 (참고 게임: 오카미), 그러나 **더 차분하고 어둡게**, **일본풍이 아니라 한국풍으로**.

| 고를 것 | 피할 것 |
|---|---|
| 로우폴리 · 스타일라이즈드 (단순한 면, 평평한 색) | 사실적인 사진 텍스처 (외곽선 셰이더로 통일이 안 됨) |
| 색이 적고 차분한 것 (먹색·회색·한지색, 바랜 녹색·갈색) — 나중에 색을 바꾸기 쉬움 | 원색이 강한 만화풍, 반짝이는 판타지풍 |
| 한옥 처마·기와·단청·장승·돌탑·소나무·초가 | 토리이(붉은 문), 일본식 지붕·석등, 사무라이·닌자, 일본 요괴 |
| URP 지원 (Lit / Simple Lit) | 자체 셰이더가 많은 팩, Built-in 전용 팩 |

- **색은 중요한 것에만**: 붉은색 = 부적·피해·체력, 푸른색 = 기력·도깨비불, 노란색 = 부적·아이템. 배경 에셋은 색이 튀지 않는 것이 좋습니다.
- **크기 기준**: 플레이어 삼각형 5천~8천 개 이하 · 일반 귀신 1천5백~3천 개 이하 · 텍스처 대부분 1024 이하(최대 2048). "Low poly", "Mobile friendly" 표시가 있으면 좋습니다.
- **쿼터뷰 고정 카메라**라 디테일은 잘 안 보입니다 → 큰 모양(실루엣)이 분명한 것이 좋습니다.

## 2. 목록 — 무엇이 필요한가

> 우선순위: ⭐ 먼저 (스타일을 정하는 것) · 🔵 슬라이스에 필요 · ⚪ 나중 (1막 정식)

### ① 화면 스타일 (⭐ 가장 먼저 — 이게 모든 에셋의 느낌을 통일함)

| 에셋 | 느낌 | 검색어 |
|---|---|---|
| 외곽선 셰이더 (URP) | 굵기가 조금씩 변하는 먹 선 | `toon outline URP`, `toon shader URP` |
| 한지 질감 그림 | 화면 전체에 얇게 덮을 종이 결 (이음매 없는 그림) | `paper texture seamless`, `rice paper texture` |
| 먹 번짐 산 배경 | 먼 산이 먹으로 번진 산수화 + 안개 | `ink wash mountains`, `chinese painting background` (사용 조건 확인) |
| 블롭 그림자 | 캐릭터 발밑 먹물 덩어리 (부드러운 원 그림 1장) | 직접 만들어도 됨 |

### ② 플레이어 캐릭터 — 부적사 (🔵)

| 에셋 | 느낌 | 비고 |
|---|---|---|
| 젊은 도사 모델 1개 | 도포 차림, 날렵한 몸, 무기 없이 부적을 던짐. 갓·상투 등 한국 느낌이면 최고, 없으면 무늬 없는 동양풍 옷 → 나중에 색을 붉은 계열(주묵 도포)로 바꿈 | 사람 뼈대(**Humanoid**)여야 애니메이션을 붙일 수 있음 |
| 애니메이션 | 서기 · 달리기 · 던지기(부적) · 주문(폭발) · 맞기 · 죽기 · 짧은 돌진(축지 회피) | **Mixamo**(mixamo.com, 무료)에서 받아 Humanoid 모델에 붙일 수 있음 |

### ③ 귀신 (🔵 슬라이스 4종 · ⚪ 1막 나머지)

| 귀신 | 느낌 | 검색어 |
|---|---|---|
| 🔵 망자 | 사람 크기, 느리게 걷는 죽은 자. 회색 피부·누더기 옷. 너무 잔인한 좀비는 피함 | `low poly zombie`, `ghoul low poly` |
| 🔵 창귀 | 마르고 작은 사람 형태, 빠르게 뛰어다님. 흐린 주황빛 | `low poly ghoul thin`, `imp`, `goblin` (색 바꿔 쓰기) |
| 🔵 도깨비불 | 모델 없음 — 바닥 1.5m 위에 떠 있는 **푸른 불덩이** (이펙트로 만듦, ⑥ 참고) | `stylized fire VFX` |
| 🔵 산군 (보스) | **호랑이**. 크고 위협적, 타락한 산신의 사자 — 어둡고 일그러진 느낌. 앞발 휘두르기·덮치기·포효 애니메이션 필요 | `low poly tiger animated` |
| ⚪ 두억시니 | 크고 단단한 탱커 귀신 (바위 변종도 같은 모델) | `low poly ogre`, `troll` |
| ⚪ 석인 | 무덤 앞 돌사람이 깨어남 (무인석·문인석 모양) | `stone golem low poly` |

- 귀신은 **반투명으로 만들지 않습니다** (불투명 + 테두리 빛 + 발광). 반투명 유령 팩은 그대로 쓰기 어렵습니다.
- 같은 모델에 색만 바꾼 **변종**을 많이 쓰므로, 색 바꾸기 쉬운(텍스처가 단순한) 모델이 좋습니다.

### ④ 지역 환경 (🔵 슬라이스 4곳 · ⚪ 1막 나머지)

> 무작위 지역은 **20m × 20m 조각**을 이어 붙여 만듭니다. 그래서 벽·담장·바위처럼 **이어 붙이기 좋은 조립식(modular) 팩**이 좋습니다.

| 지역 | 필요한 것 | 검색어 |
|---|---|---|
| 🔵 무너진 본산 · 백팔 계단 (폐사찰) | 기와지붕 건물(무너진 것도), 돌계단, 돌담, 석등, 석탑, 나무 문, 부서진 잔해 | `asian temple low poly`, `korean temple`, `pagoda low poly` |
| 🔵 안개 산길 (산길·숲) | 소나무, 바위, 풀·덤불, 흙길, 낮은 언덕 장식 | `low poly nature`, `stylized pine forest`, `low poly rocks` |
| 🔵 산 아래 마을 (거점) | 초가집, 기와집 1~2채, 싸리 울타리, 장독대, 우물, 짚더미, 수레 | `asian village low poly`, `thatched house low poly` |
| 🔵 마을 물체 | **서낭당**(오색 천을 단 나무 + 돌무더기), **장승**(웨이포인트), 궤짝(창고) | 거의 없음 → 단순 모델을 조합하거나 나중에 직접 만듦 |
| 🔵 산군의 굴 (동굴) | 바위굴 벽·천장, 큰 바위, 뼈 더미 | `low poly cave kit`, `stylized cave modular` |
| ⚪ 다랑이 논 · 화전민 마을 · 대나무 숲 · 고분 | 계단식 논둑, 불탄 초가, 대나무, 봉분·비석·석인, 폐금광 갱도·나무 버팀목 | `bamboo low poly`, `mine kit low poly`, `tomb low poly` |

- 일본 사찰 팩을 고를 때는 **토리이·일본식 석등이 없는지**, 지붕 모양이 너무 일본식이 아닌지 봅니다. 한국 전용 팩은 드물어서, "동양풍 팩 + 한국 소품 몇 개 직접"이 현실적입니다.
- 횃불·등잔은 실제 빛 대신 **스스로 빛나는 재질**로 씁니다 (성능). 빛나는 소품이 있는 팩이면 좋습니다.

### ⑤ NPC (🔵 슬라이스)

| 인물 | 느낌 |
|---|---|
| 스승 | 나이 든 도사, 위엄 있는 도포 |
| 무영 | 플레이어 또래 동료 도사 |
| 촌장 | 나이 든 마을 남자, 한복 |
| 보부상 | 등짐을 진 장사꾼 |
| 마을 사람 2~3 | 평범한 한복 차림 (색만 바꿔 여럿으로) |

- 서 있기·말하기 동작 정도면 충분합니다 (Mixamo). 초상화는 개발 중에는 **이름 붓글씨 네모**로 대신하므로 지금은 필요 없습니다.
- 한복 모델은 드뭅니다 → 동양풍 마을 사람 팩을 찾고 색을 바꾸는 방법이 현실적입니다.

### ⑥ 이펙트 (🔵)

> 사실적인 불꽃·연기 대신 **구름·소용돌이 문양**, 폭발은 **붉은 먹이 튄 원**.

| 이펙트 | 느낌 |
|---|---|
| 부적 투사체 | 노란 종이 부적이 날아감 + 짧은 꼬리 |
| 부적 폭발 | 붉은 먹이 원 모양으로 튀어 번짐 |
| 도깨비불 · 불덩이 | 푸른(변종: 붉은·흰) 불덩이, 만화풍 불꽃 |
| 맞을 때 · 귀신 사망 | 먹물이 흩어짐, 검은 연기 문양 |
| 레벨업 · 서낭당 | 금빛 운문(구름무늬)이 올라감 |
| 범위 표시 | 바닥의 빨간 원·부채꼴 (지금 조준 원 재활용) |

- 검색어: `stylized VFX`, `toon VFX URP`, `cartoon explosion`. 그림 몇 장(문양 텍스처)과 Unity 파티클로 직접 만드는 쪽이 오히려 쉬울 수 있습니다.

### ⑧ 소리 (🔵)

| 종류 | 목록 | 느낌 |
|---|---|---|
| 효과음 12개 | 부적 던지기 · 부적 적중 · 부적 폭발 · 쪽부적 · 호신부 · 제웅 · 플레이어 피격 · 귀신 사망 · 아이템 떨어짐(레어 이상 따로) · 엽전 줍기 · 레벨업 · UI 클릭 | 종이 펄럭임·붓 소리·둔탁한 타격, 엽전은 쇠 짤랑 |

## 3. 고르는 순서 (추천)

## 4. 에셋마다 확인할 것 (체크리스트)

- [ ] **사용 조건**: 상업용 게임에 써도 되는지, 고쳐 써도 되는지 (Asset Store 에셋은 보통 됨. 다른 사이트는 꼭 확인)
- [ ] **URP**: 연습 프로젝트에서 분홍색으로 나오지 않는지 (나오면 Render Pipeline Converter로 변환 시도)
- [ ] **삼각형 수**: Project 창에서 모델 클릭 → Inspector 아래 미리보기의 `Tris`
- [ ] **텍스처 크기**: 1024 이하인지 (그림 파일 클릭 → Inspector 아래 크기)
- [ ] **한국풍**: 일본풍 요소가 없는지
- [ ] **용량**: 팩 전체 크기 (Git LFS 용량 확인 [전달-07] 때 필요)
- [ ] **뼈대**: 캐릭터·귀신은 Humanoid 또는 애니메이션이 들어 있는지
