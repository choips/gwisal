**구조**

- 퀘스트 = **단계 목록**, 단계마다 목표 하나. 목표 종류를 정해 두면 새 퀘스트는 **데이터만 추가**.


| 목표 종류        | 예                       |
| ------------ | ----------------------- |
| 지역 도착        | "창귀 골짜기로 가기"            |
| 귀신 처치 (종류·수) | "장례 행렬 귀신 처치"           |
| 보스 처치        | "산군 처치"                 |
| 퀘스트 아이템 얻기   | "대원의 유품 찾기"             |
| NPC와 대화      | "무영과 대화"                |
| 원혼과 대화       | 망자의 목소리를 듣는 능력으로 원혼과 대화 |
| 물체 상호작용      | "서낭당 정화", "꽃 피우기"       |


- 상태: 잠김 → 받을 수 있음 → 진행 중 → 완료.
- **NPC 머리 위 표시**: "!" = 받을 수 있음, "?" = 완료 보고 (붓글씨 느낌).
- **추적기**: 화면 오른쪽 위에 현재 목표. **퀘스트 창(J 키)**: 막별 목록, 진행 상황, 동료 조각 수집 현황 (예: 3/6).
- **세이브**: 퀘스트 진행은 **캐릭터별**, 엔딩 여부만 **계정 공용**.
- **스토리 스킵 캐릭터**: 메인 퀘스트가 완료 상태로 시작 (웨이포인트·균열·용병 해금). **서브 퀘스트는 그대로 할 수 있음** (유품·스킬 포인트·물약 충전 획득 가능).
- 데이터 (Cursor 작업용 메모): `QuestData` (ScriptableObject: ID, 종류, 막, 시작 조건, 단계 목록, 보상, 대사 키) / `QuestManager` (귀신 처치·지역 도착·대화 같은 **게임 이벤트를 듣고** 단계를 진행 — 퀘스트마다 코드를 짜지 않음) / 퀘스트 글은 모두 **String Table**에서.

**자동 지도** (지역이 무작위 생성되므로 꼭 필요)

- 디아블로 2 방식: **탐험한 곳만** 그려짐. 미니맵(화면 구석) + 전체 지도(Tab).
- 퀘스트 목표, 웨이포인트, 출구, 거점 NPC 표시.
- **수묵 스타일** (먹 선으로 그린 지도).

### 용병

> 2026-10-13 확정. 싱글플레이에서 "혼자가 아닌 느낌" + 직업의 약점 보완. 1인 개발로 감당할 수 있게 단순하게.

**장비 3칸 — 플레이어 아이템을 그대로 사용**: **머리, 몸, 목** 3칸에 플레이어가 줍는 투구·갑옷·노리개를 끼움. **무기는 용병마다 고정**이고 레벨에 맞춰 자동으로 강해짐 → 활·화승총 같은 용병 전용 아이템을 새로 만들 필요 없음 (아이템 종류·드랍 테이블 그대로), 대신 "좋은 갑옷 하나 더 → 용병에게" 파밍 쓰임새.

**용병 3종** — 이름은 조선의 실제 군대 편제 **삼수병(三手兵)**(훈련도감의 사수·포수·살수)에서 가져오고, 치료사를 더함


| 용병         | 해금                       | 역할     | 배경                                                        | 성향 A                                   | 성향 B                                   |
| ---------- | ------------------------ | ------ | --------------------------------------------------------- | -------------------------------------- | -------------------------------------- |
| 착호갑사(捉虎甲士) | 1막 — **산군 처치 후** 산 아래 마을 | 원거리 딜러 | 조선에 실제로 있던 호랑이 사냥 부대. 산군을 잡으러 왔다가 부대를 잃고, 산군이 쓰러지자 마을에 남음 | **사수(射手)**: 활, 빠른 연사, 맞은 적 둔화          | **포수(砲手)**: 화승총, 느리지만 강한 한 방, 일직선 관통   |
| 떠돌이 검객     | 2막 — 황포 나루               | 근접 탱커  | 강을 따라 떠도는 무사. 오래전 대사형과 겨룬 적이 있어 2막 보스전 전후로 짧은 대사          | **등패수**: 칼 + 등패, 귀신의 공격을 끌어들임(도발), 단단함 | **살수(殺手)**: 쌍검, 빠른 연타, 주변 적 베기         |
| 의원         | 3막 — 일주문 야영지             | 회복·보조  | 생존자 진지의 치료사                                               | **침술사**: 주기적으로 플레이어 체력 회복, 위급할 때 큰 회복  | **약초꾼**: 탕약을 던져 공격력·이동 속도 증가 버프, 적에게 독 |


직업별 추천 조합: 부적사(원거리) ↔ 떠돌이 검객(등패수, 앞에서 막아 줌) / 퇴마검사(근접) ↔ 착호갑사·의원(침술사) / 무당(소환) ↔ 의원(약초꾼, 버프가 소환물에도 적용되면 시너지)

**능력치 (능력치 시스템 재사용)**

```
용병 체력     = 용병 종류별 기본 체력 × 레벨 성장 + 장비 체력
용병 무기 피해 = 용병 종류별 기본 무기 피해 × 레벨 성장
용병 방어·저항 = 장비에서 (플레이어와 같은 계산식)
```

- 목표 비중: 용병 피해는 **플레이어의 20~30%** (주인공을 대신하지 않고 보조). 귀신의 공격이 용병에게도 분산되어 플레이어의 압박 감소.

**조작·UI**

- **AI 자동 행동**: 따라다니며 알아서 싸우고 스킬 사용. **스킬 6칸을 차지하지 않음**.
- **용병 창**: 장비 3칸, 능력치, 성향, 해고·교체.
- **짧은 대사(바크)**: 플레이어와 같은 바크 시스템. 예) 착호갑사 "호랑이 냄새가 나는군", 의원 "무리하지 마시오".

**개발 관점**

- **아군 AI 공용화**: 용병·무당 소환물·부적사의 제웅·종이 학이 모두 "아군 AI"(따라다니기, 목표 고르기) 사용 → **한 번 만들어 같이 씀**.
- **개발 순서**: 1막 완성 후 **착호갑사 먼저** (아군 AI를 여기서 만들어 두면 무당이 쉬워짐) → 추천 순서 **용병(착호갑사) → 퇴마검사 → 무당**.
- ⚠️ 성능: 아군 개체 수 상한에 **용병 1명도 포함** (예: 소환물 6 + 용병 1 = 최대 7).
- 밸런스 엑셀 **용병 시트**: 종류·성향별 기본 체력, 무기 피해, 공격 간격, 고용 비용.

### 슬라이스 스토리 흐름 상세 (S4 — 2026-10-14 확정)

> 대사는 모두 `Docs/기획/01_스토리_세계관.md` → "슬라이스 대본". 여기는 그 대본을 **화면에서 어떻게 보여 주는지**를 정합니다. 숫자 원본은 밸런스 엑셀 **"상수"** 시트(`Dialogue…`·`Bark…`·`Voice…`·`Minimap…`·`Shop…`·`NpcTalkRange`·`BossIntro…`). 화면 글자는 모두 **String Table**.
> 정한 것: ① 대화 중 **게임 멈춤** ② 초상화는 개발 중 **이름 붓글씨 네모** ③ 튜토리얼은 **직접 해내면 다음 문구** ④ 자동 지도는 **미니맵 + Tab 겹쳐 보기** ⑤ 상점은 **장비 8개 + 팔기** ⑥ 바크는 **상황 5개만** ⑦ 보스 등장 연출은 **처음 한 번만**.

**① 대화창**

- 화면 아래 약 1/4 높이. 왼쪽 = **플레이어 초상화**, 오른쪽 = **상대 초상화**, 가운데 = 이름 + 대사. 말하는 쪽은 밝게, 듣는 쪽은 어둡게.
- **임시 초상화 = 이름 붓글씨 네모**: 먹색 네모 안에 흰 글씨로 인물 이름. 인물 데이터에 그림이 비어 있으면 자동으로 이 네모를 씀 → 나중에 그림만 넣으면 바뀜. 표정 칸(기본·슬픔/분노·놀람)도 미리 둠.
- 글자는 한 자씩 나옴 (초당 `DialogueCharsPerSecond` = 40자). **클릭**: 글자가 나오는 중이면 그 줄을 한 번에 다 보여 주고, 다 나왔으면 다음 줄. 화면 오른쪽 위 **[건너뛰기]** = 대화 전체를 넘김 (단, 대사에 붙은 이벤트 — 퀘스트 진행·서낭당 활성화·상점 열기 — 는 **그대로 실행**).
- 대화창이 떠 있는 동안 **게임 멈춤** (대화창은 멈춘 시간과 상관없이 움직임).
- 대본의 *연출 지시*는 줄마다 붙는 **이벤트**로 처리: 화면 하얗게 번짐(스승), 먹 번짐 + 정적(반전), 카메라 다가가기, 인물 퇴장, 퀘스트 진행, 서낭당 활성화, 상점 열기.
- **NPC 말 걸기**: NPC를 클릭 → `NpcTalkRange`(3m) 안까지 걸어가서 대화 시작. 대본 대화는 처음 한 번만, 그 뒤에는 짧은 한마디 + 기능 버튼:

| NPC | 산군 처치 전 | 산군 처치 후 | 버튼 |
| --- | --- | --- | --- |
| 무영 | "마을은 내가 볼게. 넌 산군을." | "풀려난 사람들… 이제 편히 갔으면 좋겠어." | — |
| 촌장 | "뒷산 굴입니다. 부디 조심하시오." | "산이 조용해졌습니다. 고맙소, 도사님." | — |

- **추적기**: 화면 오른쪽 위, **미니맵 바로 아래**. 퀘스트 이름(작게) + 목표(크게). 새 목표는 먹 번지듯 나타나고 짧은 소리, 퀘스트 완료 때 붓글씨 "완료" 1.5초.

**④ 장면 대사 · 망자의 목소리**

- **장면 대사**(대본의 부적사 혼잣말 — "귀신이 살려 달라고?", "불이 떠다녀…", "무영의 표시군" 등): 바크와 같은 모양(플레이어 머리 위 또렷한 글자, 2.5초). 정해진 자리(S3 "고정 이벤트 자리")에 처음 들어갈 때 **한 번만**. 장면 대사가 떠 있으면 바크는 나오지 않음.
- **망자의 목소리**(창귀 "살려 줘…" 등, 2페이즈 창귀 "싫어… 먹지 마…", 풀려난 창귀들): 그 귀신 머리 위에 **흐릿한 회색 붓글씨**(바크와 구분), 0.5초 나타남 → 2.5초 → 1초 사라짐. 창귀 `VoiceSubtitleRadius`(10m) 안에 들어가면 나옴, 지역마다 최대 `VoiceSubtitleMaxPerRegion`(3)번, 사이 `VoiceSubtitleInterval`(20초).
- **기록 조각**(안개 산길 쪽지, 선택): 바닥의 쪽지를 클릭 → 화면 가운데 작은 한지 창에 글, 클릭하면 닫힘. 게임 멈춤.

**⑥ 두루마리 컷신 (프롤로그 4장)**

- **새 캐릭터로 처음 시작할 때만** 재생 (이어하기 때는 없음). 검은 화면 → 두루마리가 가로로 펼쳐짐(1초) → 그림 4장이 차례로, 장면마다 천천히 확대·이동 + 아래 자막 2줄(한 줄씩, 줄당 약 5초) → 두루마리가 말리며 본산으로. 전체 약 1분.
- **클릭** = 다음 자막(마지막 자막이면 다음 그림), **[건너뛰기]** = 컷신 전체. 음성 없음 (슬라이스).
- 임시 그림 4장 (가로 그림, 1920×1080 이상). 그림이 비어 있으면 회색 바탕 + 장면 번호로도 끝까지 동작해야 함 (그림 없이 먼저 만들 수 있게).

**⑦ 자동 지도 (미니맵 + Tab 겹쳐 보기)**

- **미니맵**: 화면 오른쪽 위, 한 변 `MinimapSize`(200픽셀) 정사각형, 플레이어가 가운데. 지도 위쪽 = 게임 화면 위쪽(카메라 방향에 맞춤).
- **Tab 겹쳐 보기**: Tab을 누르면 켜지고 다시 누르면 꺼짐. 게임 화면 위에 반투명(`MapOverlayAlpha` 0.7) 큰 지도를 겹쳐 그림, **게임은 멈추지 않음** (디아블로 2 방식).
- **탐험한 곳만** 보임: 플레이어 주변 `MinimapRevealRadius`(15m) 안이 밝혀짐.
- 표시: 플레이어(붉은 화살표) · 입구·출구 · 서낭당·장승 · NPC(마을에서) · 퀘스트 목표(붉은 낙관 모양, 위치를 알 때만). **귀신은 표시 안 함**.
- 모양: 슬라이스는 **한지색 바탕 + 먹색 길**만 (수묵 붓 터치 꾸밈은 이후).
- 탐험 기록: 지역을 떠나면 지움. 사망 후 같은 시드로 다시 불러올 때(S7)는 **남김** (메모리에만, 세이브에 안 넣음).

**⑧ 산 아래 마을 (거점)**

- 크기: 약 **40m × 40m** (타일 2×2칸 정도), 모든 기능을 한 바퀴 **30초 안에**. 임시 모양: 집 = Cube, NPC = 색이 다른 Capsule + 이름표.
- 배치: 남쪽 = 입구(안개 산길에서 들어옴) · 입구 바로 옆 = **서낭당** · 가운데 광장 = 무영·촌장 · 장독대 옆 = 보부상 · 북쪽 = **뒷산 출구**(산군 퀘스트 전까지 나무 울타리로 막힘).
- **탈환 전**: 귀신 약 12마리를 씬에 미리 놓음 — 망자 무리 2개(4마리씩) + 창귀 무리 1개(4마리). NPC는 숨어 있어 안 보임.
- **탈환 후**(마을 귀신 전부 처치): 안전 지역 — 스킬 사용 불가(클릭은 이동·대화만), 귀신이 들어오지 않음, 들어올 때마다 **물약 자동 충전**. 무영·촌장·보부상이 나타남.
- **보부상 상점** (탈환 후, 첫 대화 뒤 [거래]):
  - 왼쪽 = 상점 물건, 오른쪽 = 가방. 물건 **`ShopItemCount`(8)개**: 노멀 4 + 매직 4, 매직 하나가 `ShopRareChance`(10%) 확률로 레어. **부적사가 쓸 수 있는 장비만**, 아이템 레벨 = 플레이어 레벨.
  - 물건은 **마을에 들어올 때마다 새로** (같은 방문 동안은 그대로).
  - **사기**: 물건 오른쪽 클릭 → 엽전이 모자라면 알림. 값 = 아이템 가치 (03 "엽전 경제" 공식).
  - **팔기**: 상점이 열린 동안 가방 장비를 오른쪽 클릭 → 바로 팔림 (레어 이상만 확인 창). 값 = 아이템 가치 × 25%.
  - **되사기**: 방금 판 물건 최근 `ShopBuybackSlots`(5)개를 판 값 그대로 다시 살 수 있음 (실수 방지). 마을을 떠나면 비워짐.
  - 일괄 판매는 슬라이스 이후.

**⑨ 서낭당 · 장승 (웨이포인트)**

- **서낭당**(마을): 촌장 대화 뒤 클릭하면 활성화 (퀘스트 목표). **장승**(백팔 계단·안개 산길 입구 칸): 옆을 지나가면 자동 활성화.
- 활성화된 곳을 클릭 → 이동 창: [산 아래 마을] [백팔 계단] [안개 산길] — 안 가 본 곳은 회색. 무작위 지역으로 가면 **새 시드** (S3 규칙).
- 산군의 굴은 마을 뒷산 출구에서 바로 가므로 웨이포인트 없음. 귀환(B)은 마을로 **편도** (S6).

**⑩ 산군의 굴 연출**

- 굴 입구에서 몇 걸음 → 부적사 장면 대사 "피 냄새… 그리고 울음소리." → 안쪽 넓은 곳에 들어서면 **입구 닫힘**.
- **보스 등장 연출 (처음 한 번만)**: 플레이어 조작 멈춤 → 카메라가 `BossIntroCameraTime`(2초) 동안 산군에게 다가감 → 산군 포효 몸짓 + 붓글씨 "산군(山君)" `BossIntroNameTime`(1.5초) → 카메라 복귀(1초) → 전투 시작. 연출 중 산군은 공격하지 않음. 클릭하면 건너뜀.
- **다시 들어갈 때**(사망 후 재도전, 클리어 뒤 다시 잡기): 카메라 연출 없이 붓글씨 이름만 1초.
- 처치 → 창귀 해방(S2) + 풀려난 창귀 목소리 → **반전**: 화면 가장자리 먹 번짐 + 소리 끊김 1초 정적 → 대화창(산군 줄) → 산군이 흩어짐 → 무영이 굴 입구에서 뛰어와 대화 → 클리어 화면(S7).
- 반전·무영 대화·클리어 화면은 **첫 처치 때만**. 다시 잡을 때는 바크 "산이 조용해졌군."만.

**데이터 (Cursor 작업용 메모)**

- `SpeakerData`: ID, 이름 키, 초상화(표정 3칸 — 비면 이름 네모 자동).
- `DialogueData`: 줄 목록 — 화자, 왼쪽/오른쪽, 표정, 대사 키, 이벤트(없음 / 퀘스트 진행 / 웨이포인트 활성화 / 상점 열기 / 화면 하얗게 / 먹 번짐 / 카메라 이동 / 인물 퇴장).
- `QuestData`: 단계 목록 — 목표 종류(지역 도착 / 지역 귀신 전부 처치 / 보스 처치 / NPC 대화 / 물체 상호작용), 대상 ID, 목표 문구 키. `QuestManager`가 게임 이벤트를 듣고 진행 (퀘스트마다 코드를 짜지 않음). 진행은 **캐릭터별 세이브**.
- `TutorialHintData`, `BarkData`(상황 → 대사 키 목록), `ScrollCutsceneData`(그림·움직임·자막 키), `ShopData`(물건 수·등급 비율).
- 세이브에 새로 들어가는 것: 퀘스트 단계, 활성화한 웨이포인트, 본 컷신·보스 연출 여부, 마을 탈환 여부, 산군 첫 처치 여부. 세이브에 칸을 더할 때는 **맨 뒤에 추가**.
